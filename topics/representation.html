FM Synthesizer Audio-Parameter Shared Embeddings

FM 合成器的音訊-參數共享嵌入

David Braun, Adam Finkelstein
arXiv:2608.18226 · cs.SD · 投稿submitted 2026-08-18
abspdfhtmlcited by
為什麼挑這篇：這篇論文最反直覺的地方是:模型容量跟泛化能力並不成正比。DX7-GNN 只用 338 萬參數,在保留一半合成器拓樸不給訓練看的測試上做到 R@1 52.2%,比參數量多 17 倍的 Transformer(5,720 萬參數,R@1 34.6%)高出將近 18 個百分點,比 Highway Network(R@1 24.8%)高 27 個百分點。而且這個泛化能力幾乎全靠訓練時的算子交換增強撐起來——拿掉它,DX7-GNN 自己的 R@1 就從 52.2% 崩到 13.5%,證明真正在教模型「拓樸可以互換」的是資料增強,不是架構本身單獨的功勞。Why this one: The most counterintuitive result here is that model capacity and generalization pull apart. DX7-GNN, with only 3.38M parameters, reaches R@1 52.2% on a test that withholds half the synthesizer topologies from training -- nearly 18 points ahead of the 57.2M-parameter Transformer (R@1 34.6%, 17x more parameters) and 27 points ahead of the Highway Network (R@1 24.8%). And that generalization leans almost entirely on the operator-swap augmentation used during training: remove it, and DX7-GNN's own R@1 collapses from 52.2% to 13.5%, showing the augmentation -- not the architecture alone -- is what actually teaches the model that topologies are interchangeable.

動機Motivation

音效設計師想找到心裡想的合成器音色,常常只能在龐大的預設庫裡一個一個試聽,非常沒效率。這篇論文指出現有做法把合成參數當成扁平向量處理,等於丟掉了訊號路由方式跟參數之間交互作用產生的聲音結構——把 Yamaha DX7 這種六個算子可以接成 32 種拓樸的合成器,硬是用一個類別標籤代表演算法,模型自然學不到「換一種拓樸結構」時聲音會怎麼變,也就沒辦法泛化到訓練時沒見過的路由方式。

Sound designers routinely audition preset libraries one by one, hunting by ear for a timbre they have in mind -- a slow, inefficient search. This paper argues existing methods treat synthesis parameters as flat vectors, throwing away the signal-routing structure and parameter interactions that actually shape the sound. Take the Yamaha DX7, whose six operators can be wired into 32 distinct routing topologies: encoding "which algorithm" as a single categorical label means a model never learns how sound changes under a different routing structure, so it cannot generalize to topologies unseen during training.

背景與相關研究Introduction & Prior Work

自動合成器編程這個題目上,先前做法包括監督式回歸(Yee-King et al., 2018)、梯度優化、演化搜尋(NAS-FM, Ye et al., 2023)、以及強化學習(InverSynth II, Barkan et al., 2023)。專門處理 FM 合成的工作裡,NAS-FM 同時搜尋拓樸與頻率比,但沒辦法幫沒見過的拓樸編碼預設;DiffMoog 這個可微分模組化合成器發現 FM 調變鏈在梯度優化下很難收斂;Le Vaillant et al.(2024)學到了 DX7 的編碼,但演算法仍是 one-hot 類別參數,一樣無法泛化到新拓樸;Param2Tok(Hayes et al., 2025)編碼參數並找出置換對稱性,但訊號路由依然是 one-hot。

另一條線是把 CLAP(Elizalde et al., 2023)的音訊-文字對比學習目標,換成 SLAP(Guinot et al., 2025)這種非對比、BYOL 風格的訓練方式,在檢索上勝過 CLAP。這篇論文的差異在於同時做兩件事:把 SLAP 的訓練目標從音訊-文字改成音訊-參數配對,並設計一個訊息傳遞方式模仿 FM 訊號處理本身的圖神經網路參數編碼器,靠共享權重讓網路可以處理訓練時沒見過的任意拓樸。

Prior work on automatic synthesizer programming spans supervised regression (Yee-King et al., 2018), gradient-based optimization, evolutionary search (NAS-FM, Ye et al., 2023), and reinforcement learning (InverSynth II, Barkan et al., 2023). Within FM synthesis specifically, NAS-FM searches jointly over topology and frequency ratios but cannot encode presets for unseen topologies; DiffMoog, a differentiable modular synthesizer, reports FM modulation chains failing to converge under gradient optimization; Le Vaillant et al. (2024) learn DX7 encodings but still treat the algorithm as a one-hot categorical parameter, again blocking generalization to new topologies; Param2Tok (Hayes et al., 2025) encodes parameters and discovers permutation symmetries but keeps routing as one-hot.

Separately, CLAP (Elizalde et al., 2023) built joint audio-text embeddings via contrastive learning, and SLAP (Guinot et al., 2025) replaced the contrastive objective with a non-contrastive, BYOL-style one that outperforms CLAP on retrieval. This paper's departure is doing both at once: adapting SLAP's objective from audio-text to audio-parameter pairs, and designing a graph neural network parameter encoder whose message passing imitates FM signal processing itself, with shared weights letting it handle arbitrary topologies never seen in training.

方法Method

核心是 DX7-GNN:把六個算子當成圖節點,調變連接與回授迴路當成有向邊,145 個 DX7 參數(123 個 [0,1] 浮點數、22 個整數)先轉成每個節點 47 維特徵,再用輸入 MLP 投影到 384 維基底特徵。九層(L=9)訊息傳遞裡,每層先依邊權重(調變邊權重 1,回授邊權重是可學習的單調重映射乘上一個可學習係數)聚合鄰居訊息,再用 FiLM(特徵層級線性調製)把聚合訊息注入基底特徵,做完層正規化與殘差連接後,乘上重映射過的輸出電平——這一步刻意模仿 DX7 真正的訊號流程。所有節點在所有層共享同一套訊息傳遞權重,這是讓模型能吃任意拓樸、又不會因為深度增加而過度平滑的關鍵設計。訓練目標把 SLAP 的線上/目標雙編碼器架構(EMA 更新率 τ=0.98)從音訊-文字換成音訊-參數,在 3.14 萬筆 DX7 預設(DX7AllTheWeb 資料集)上訓練。

在所有 32 種演算法都訓練過的隨機切分下,DX7-GNN 與 Transformer 打成平手(R@1 86.1%、R@10 99.5%、MRR 0.917);但換成刻意保留一半拓樸不給訓練看的「交錯演算法切分」測試泛化能力時,DX7-GNN 的 R@1 52.2%、R@10 88.5%、MRR 0.652,大幅超過 Transformer(R@1 34.6%、MRR 0.470)與 Highway Network(R@1 24.8%、MRR 0.365),而且 DX7-GNN 只用 338 萬參數,比 Transformer 的 5,720 萬參數少了 94%。消融實驗顯示,拿掉算子交換增強後 R@1 從 52.2% 崩到 13.5%,拿掉回授邊則降到 49.5%,改用全連接拓樸更是掉到 30.9%,證明真正的路由結構、而不只是模型容量,才是泛化的關鍵。

The core is DX7-GNN: operators become graph nodes, modulation connections and feedback loops become directed edges. The 145 DX7 parameters (123 continuous floats in [0,1], 22 integers) are first turned into 47-dim per-node features, then projected by an input MLP to 384-dim base features. Across 9 message-passing layers, each layer aggregates neighbor messages weighted by edge type (modulation edges weight 1; feedback edges weighted by a learned monotonic remapping times a learned scalar), injects the aggregated message into the base features via FiLM conditioning, then multiplies the result -- after layer norm and a residual connection -- by a remapped output level, deliberately mirroring DX7's actual signal flow. All nodes share the same message-passing weights across all layers, the key design letting the model handle arbitrary topologies without oversmoothing as depth grows. The SLAP training objective's online/target dual-encoder setup (EMA rate τ=0.98) is adapted from audio-text pairs to audio-parameter pairs, trained on 31,443 DX7 presets from the DX7AllTheWeb dataset.

Under a random split where all 32 algorithms appear during training, DX7-GNN ties with the Transformer baseline (R@1 86.1%, R@10 99.5%, MRR 0.917); but under an interleaved-algorithm split that deliberately holds out half the topologies to test generalization, DX7-GNN reaches R@1 52.2%, R@10 88.5%, MRR 0.652 -- far ahead of the Transformer (R@1 34.6%, MRR 0.470) and Highway Network (R@1 24.8%, MRR 0.365) baselines, despite using only 3.38M parameters versus the Transformer's 57.2M (94% fewer). Ablations confirm the routing structure itself matters: removing the operator-swap augmentation collapses R@1 from 52.2% to 13.5%, removing feedback edges drops it to 49.5%, and switching to a fully-connected topology drops it further to 30.9% -- capacity alone doesn't explain the gap.

限制Limitations

作者列出五點限制:一、評測只做在 DX7 這種算子結構完全相同的合成器上,能否泛化到結構迥異的其他合成器還不清楚;二、3.14 萬筆預設在 32 種演算法間分布不均(每種 116 到 3,758 筆不等);三、每筆預設只在單一音高與力度(C4、velocity 85)上render,沒有涵蓋音高、力度相關的音色變化;四、所有結果都只跑了一次訓練,超參數搜尋是在凍結的音訊編碼器潛在特徵上做,而不是更昂貴的端到端搜尋;五、音訊編碼器完全沒碰過複音 MIDI,作者認為這會是更有用的後續方向。

The authors list five limitations: (1) evaluation covers only the DX7, whose operators are structurally identical, so generalization to synthesizers with heterogeneous structure is untested; (2) the 31,443 presets are imbalanced across the 32 algorithms (116 to 3,758 presets each); (3) every preset is rendered at a single pitch and velocity (C4, velocity 85), missing pitch- and velocity-dependent timbre variation; (4) all results come from single training runs, and the hyperparameter search used frozen audio-encoder features rather than costlier end-to-end search; (5) the audio encoder was never trained on polyphonic MIDI, which the authors flag as a more useful future direction.

討論Discussion

這篇論文最能撐住「結構歸納偏好有用」這個主張的,是消融實驗裡數字一路往下掉的軌跡:52.2%(完整模型)、49.5%(拿掉回授邊)、30.9%(全連接拓樸)、13.5%(拿掉算子交換增強),四個數字排成一列,講的是同一件事——路由結構本身帶進來的資訊,不是靠模型容量硬補就能補上的。

另一個佐證是 timbremetrics 三元組一致性測試:這個只在 FM 合成資料上訓練的音訊編碼器拿到 68.4~69.3%,已經逼近在海量通用音訊資料上訓練的 LAION-CLAP(70.8~71.8%)。作者也誠實地把「輸出電平重映射學出跟 DX7 指數增益曲線相似的凸函數」這種可解釋的副產品秀出來,但沒有誇大——強調這只是在單一合成器、單一取樣點上驗證,還沒證明能推廣到異質合成器或效果鏈這種更複雜的圖結構。

The strongest support for "structural inductive bias matters" here is the descending trail of ablation numbers: 52.2% (full model), 49.5% (no feedback edges), 30.9% (fully-connected topology), 13.5% (no operator-swap augmentation) -- four numbers in a row all pointing at the same fact, that the information carried by routing structure itself can't be substituted for with raw model capacity.

A second piece of evidence is the timbremetrics triplet-agreement test: an audio encoder trained exclusively on FM synthesis data scores 68.4-69.3%, closing in on LAION-CLAP's 70.8-71.8% despite the latter being trained on vastly more general audio. The authors are also honest about scope: they show the interpretable byproduct that the learned output-level remapping resembles DX7's exponential gain curve, but don't overclaim -- the validation is on one synthesizer at one sampling point, with generalization to heterogeneous synthesizers or more complex graphs like effect chains still unproven.

Why GPT-Style Models Do Not Directly Transfer to Symbolic Music: Compression in the Wrong Coordinate System

為什麼 GPT 式模型無法直接轉移到符號音樂:錯誤座標系統裡的壓縮

Yi Wang
arXiv:2608.18025 · cs.LG, cs.AI, cs.SD · 投稿submitted 2026-08-18
abspdfhtmlcited by
為什麼挑這篇：這篇論文最反直覺的證據,是壓縮 token 序列的長度跟預測所需的位元數其實是兩回事:把 REMI 式事件序列(J,每事件 2.42301 bits)再套一層 BPE(K)雖然讓序列長度縮短 71.07%,但預測所需位元數反而多了 14.00%,達到 2.76234 bits/event;相對地,論文自己設計的座標感知編碼(D)不需要壓縮序列長度,單靠拆解時間、正規化音高等操作,就把位元數壓到 1.81358,比 J 低 25.15%。同樣的邏輯也出現在音高處理上:把移調量獨立析出、只讓模型看正規化後音高(G)比把移調後的絕對音高直接餵給模型(F)少了 39.57% 的位元數(1.813795 對 3.001370)。Why this one: The most counterintuitive evidence here is that shrinking a token sequence and shrinking the bits needed to predict it are two different things: layering BPE (K) on top of a REMI-style event stream (J, 2.42301 bits/event) shortens the sequence by 71.07%, yet costs 14.00% more predictive bits (2.76234 bits/event); the paper's own coordinate-aware encoding (D) needs no sequence compaction at all -- just decoupled time and canonicalized pitch -- and still reaches 1.81358 bits/event, 25.15% below J. The same pattern shows up in pitch handling: separating out the transposition shift and showing the model only canonical pitch (G) costs 39.57% fewer bits than showing it the shifted absolute pitch directly (F) -- 1.813795 versus 3.001370.

動機Motivation

GPT 式模型能在語言上成功,常被歸功於用有限的離散詞彙表示可重複使用的單元。這個想法後來被搬到符號音樂上:把和絃、動機、樂句這類會重複出現的音樂結構,當成跟語言詞彙類比的「可重複使用單元」去做斷詞。

作者認為這個類比抓錯重點——斷詞真正帶來的優勢不是「找到可以重複組合的單元」本身,而是壓縮:有效的壓縮需要一套座標系統,讓重複出現的規律性在這套座標下形成穩定、可預測的條件分布。換句話說,真正該問的問題不是「音樂裡有沒有更大的可重複組合」,而是「該用什麼座標系統,才能讓音樂事實變得可以被預測性地壓縮」。

GPT-style models succeed on language partly because they represent reusable units through a finite discrete vocabulary. That idea has been carried over to symbolic music by treating recurring structures like chords, motifs, and phrases as reusable units analogous to linguistic tokens.

The author argues this analogy misses the point: tokenization's real advantage isn't finding reusable combinations, but compression -- and effective compression needs a coordinate system in which recurring regularities form stable, predictable conditional distributions. The real question isn't whether music has larger reusable combinations to find, but which coordinate system makes musical facts predictively compressible in the first place.

背景與相關研究Introduction & Prior Work

符號音樂領域已經有不少 GPT 式的斷詞與生成系統:Music Transformer(Huang et al., 2018)與 Pop Music Transformer(Huang & Yang, 2020)把音樂事件序列化後直接餵給 Transformer;MusicBERT(Zeng et al., 2021)延伸出專屬符號音樂的預訓練;Museformer(Yu et al., 2022)則用階層式注意力去捕捉樂句結構。另外也有專門針對符號音樂做位元組對編碼(BPE)的工作(Fradet et al., 2023a),以及討論時間、時值斷詞方式對結果影響的工作(Fradet et al., 2023b)。

這篇論文的差異在於,它把上述這些系統全部歸為同一類問題——「怎麼把音樂事件序列化、組合成 token」——但作者認為這條路線從一開始就問錯問題:序列化與組合是編碼操作,跟座標系統的建構是兩回事。論文用自己複刻的 REMI 式事件序列(J)加 BPE(K)當作對照組直接證明這點:BPE 讓序列長度縮短 71.07%,預測所需位元數卻反而多了 14.00%,證明「序列變短」跟「預測變容易」並不是同一件事。

Symbolic music already has plenty of GPT-style tokenization and generation systems: Music Transformer (Huang et al., 2018) and Pop Music Transformer (Huang & Yang, 2020) serialize musical events straight into a Transformer; MusicBERT (Zeng et al., 2021) extends pretraining specifically to symbolic music; Museformer (Yu et al., 2022) uses hierarchical attention to capture phrase structure. There's also work applying byte-pair encoding (BPE) specifically to symbolic music (Fradet et al., 2023a), and work examining how time/duration tokenization choices affect results (Fradet et al., 2023b).

This paper's difference is treating all of the above as the same kind of question -- how to serialize and combine musical events into tokens -- and arguing that framing is wrong from the start: serialization and combination are coding operations, distinct from constructing a coordinate system. The paper proves this directly with its own REMI-style control (J) plus BPE (K): BPE shortens the sequence by 71.07% yet costs 14.00% more predictive bits, showing a shorter sequence is not the same thing as an easier-to-predict one.

方法Method

核心框架分成兩條原則。「事實—token 邊界」(預測有效性原則)決定哪些客觀事實該進入 token:「解耦」拿掉不同物理因子之間人為的耦合項(例如把 G(FA, FB, FAB) 簡化成 G(FA, FB));「去巢化」則把已知的可逆變換明講出來,而不是要模型自己重新學一次。這篇論文把這套原則具體實作成:把音樂事件內容(類型、音高、時值)跟起始時間分開表示;把起始時間拆成小節內進度、拍內相位、小節、四小節、十六小節等多尺度週期座標,搭配成對的時間注意力偏置項。

「token—狀態邊界」(關聯無損性原則)則規定:只要一段關係要靠上下文才能決定,就不該在斷詞階段先把它定死。論文把這條原則用在音高上做了三種操作的對照:把音高拆成音高類別加八度(可逆重參數化)、把移調量單獨析出後只讓模型看正規化音高(G)、以及把音高投影到半音或五度圈這種固定的音樂理論幾何上(E、I)。模型骨幹是 16 層、寬度 64 的因果 Transformer(共 81.7 萬參數),主要在 Pop-K 資料集(30.4 萬首訓練、各 1,024 首驗證與封存測試)上訓練,並在 ComMU(9,299 首)上獨立複現。

The framework splits into two principles. The Fact-Token Boundary (Predictive Effectiveness Principle) decides which objective facts enter a token: decoupling removes artificial coupling between physically distinct factors (e.g. simplifying G(FA, FB, FAB) to G(FA, FB)); denesting makes known reversible transforms explicit instead of forcing the model to relearn them. Concretely, the paper separates event content (type, pitch, duration) from onset time, then decomposes onset time into multi-scale periodic coordinates -- within-bar progress, within-beat phase, bar, four-bar, sixteen-bar -- paired with temporal attention biases.

The Token-State Boundary (Relational Losslessness Principle) says any relation that needs context to resolve should not be fixed at tokenization time. The paper tests this on pitch with three operations: splitting pitch into class plus register (a reversible reparameterization), isolating the transposition shift so the model sees only canonical pitch (G), and projecting pitch onto fixed music-theoretic geometries like the chromatic or circle-of-fifths space (E, I). The backbone is a 16-layer, width-64 causal Transformer (817,107 parameters total), trained mainly on Pop-K (303,767 training songs, 1,024 each for validation and sealed test), with an independent replication on ComMU (9,299 songs).

限制Limitations

作者自己劃定的範圍是:這些結論只在受測的表示法、一個受限的模型規模(81.7 萬參數)、三個種子、五個目標等效訓練週期內成立;預測位元數是「相對於這個模型」的指標,不是全域最優的編碼,也不是音樂品質的量尺。論文也承認 H(可逆重參數化)跟 D 的比較「不是為了做等價性檢定而設計的」,兩者位元數差距只有 +0.008324,而且有一個保留種子的結果方向是反過來的。

另外,E、I 這兩個固定幾何投影被拒絕的結論,只能說「這兩種特定的替代方式」不好,不能推論成「所有音高幾何先驗都沒用」;成對時間注意力偏置改善了位元數,但論文也明講這「本身並不足以證明模型真的學到了樂句、終止式、動機或聲部這些結構」。

The authors bound the claims themselves: the conclusions hold only for the tested representations, a constrained model scale (817,107 parameters), three seeds, and five target-equivalent training epochs. Predictive code length is a model-relative metric, not a global coding optimum or a measure of musical quality. The authors also note the H (reversible reparameterization) versus D comparison "was not designed as an equivalence test" -- the gap is only +0.008324 bits/event, and one held-out seed reverses direction.

Rejecting the two fixed geometric projections (E, I) only rejects "these particular replacements," not all forms of pitch geometry as a prior. And while the pairwise temporal attention bias improves code length, the paper states plainly this alone "does not establish phrase, cadence, motif, or voice structural understanding."

討論Discussion

這篇論文最值得討論的地方,是它把兩個看似理所當然的直覺同時打臉:第一,序列壓得越短不代表模型越好預測——BPE 把序列縮短 71.07%,位元數卻多付 14.00%;第二,套用音樂理論裡現成的幾何先驗(半音圈、五度圈)不但沒有幫助,反而讓位元數比不套用還差(E 比 D 多 0.0769、I 比 D 多 0.2290)。這暗示過早把「音高之間的關係」用固定幾何鎖死,反而會讓模型少掉本來可以自己學出來的上下文彈性。

真正有效的操作反而是看起來最不花俏的兩招:把時間拆成多尺度週期座標(讓位元數降 42.73%),以及把移調量單獨析出、只讓模型看正規化音高(讓位元數降 39.57%)。這兩者的共同點是:都沒有預先幫模型決定「音符之間的關係是什麼」,只是把物理上本來就分離的因子(時間位置、移調量)在座標上也分離開來,關聯本身留給模型的上下文去算。這對想要把「音樂理論知識」直接編碼進斷詞方案的做法,是一個值得三思的提醒。

The most discussion-worthy part of this paper is that it overturns two intuitions people usually take for granted. First, a shorter sequence doesn't mean easier prediction -- BPE shortens the sequence by 71.07% yet costs 14.00% more bits. Second, applying off-the-shelf music-theoretic geometric priors (chromatic circle, circle of fifths) doesn't help either -- it makes things worse than not using them at all (E costs 0.0769 more than D, I costs 0.2290 more). That suggests locking pitch relations into a fixed geometry too early strips away contextual flexibility the model could otherwise learn on its own.

What actually works are the two least flashy moves: decomposing time into multi-scale periodic coordinates (cutting code length by 42.73%) and isolating the transposition shift so the model only sees canonical pitch (cutting it by 39.57%). Both share the same trick -- neither pre-decides what the relation between notes is; they just separate factors that are already physically distinct (position in time, transposition amount) in the coordinate system, leaving the relation itself to the model's context. That's a worthwhile caution for anyone trying to bake music-theory knowledge directly into a tokenization scheme.

動機Motivation

音樂基礎模型(如 MERT、MusicFM、MusicGen)訓練完成後,幾乎都是被凍結起來當特徵萃取器用,但要從哪一層抽取特徵目前「多半是憑經驗決定」——固定用某個深度,或乾脆把好幾層融合起來,背後沒有一套原則性的理解去說明為什麼某些層轉移效果比較好。

作者認為,單純看下游任務的 probing 分數不夠——這種分數主要反映「跟任務相關的訊息是不是線性可分」,而不是描述表徵空間本身是怎麼被組織起來的;而且 probe 的容量、模型架構本身都會影響排名,所以下游表現本身無法完整刻畫表徵品質。他們想問的問題是:能不能找到一組不需要標籤、不需要訓練的「內在指標」,直接從表徵的幾何特性去預測哪一層會是好的特徵萃取層?

Music foundation models such as MERT, MusicFM, and MusicGen are almost always frozen after pretraining and used purely as feature extractors, but which layer to extract from is, in the authors' words, largely heuristic — a fixed depth or an ad hoc multi-layer fusion, with no principled account of why some layers transfer better than others.

The authors argue that downstream probing scores alone are insufficient: they mostly reflect whether task-relevant information happens to be linearly separable, not how the representation space itself is organized, and probe capacity plus architecture choices can distort the ranking. Their question is whether a set of label-free, training-free intrinsic metrics can predict, directly from a layer's geometric properties, which layer will make a good feature extractor.

背景與相關研究Introduction & Prior Work

內在指標這條路子在音樂領域之外已經有人做過:電腦視覺的 RankMe 把嵌入的有效秩跟下游遷移能力連結起來;LiDAR 針對聯合嵌入架構把秩的評估做得更細緻;語音與音訊領域也有以秩為基礎的模型評估方法;幾何分析(內在維度、各向異性、曲率)則揭露了不同訓練目標下,表徵性質隨深度變化的階段性轉折。

音樂領域本身也有零星觀察:Jukebox 的中間層在 MIR 任務上表現最好;MusicFM、MuQ 呈現「淺層偏聲學、深層偏語意」的趨勢,而且中間層常常打得贏加權融合;MERT、MusicGen 上,內容屬性(音高、和絃根音)隨深度愈來愈容易被線性探測到,風格屬性則不然。這些過去的工作大多是針對特定任務做 probing、做局部介入,或做事後的特徵探勘,並沒有系統性地刻畫表徵幾何本身。

這篇論文的差異在於它是「第一個」對 12 個音樂基礎模型、橫跨三種預訓練典範(遮罩建模、自迴歸、對比學習)做系統性逐層內在特性分析,而且直接去測試這些免標籤指標能不能當作實務上的選層依據,而不是像過去那樣停留在觀察層級。

Intrinsic-metric approaches predate this outside music: in vision, RankMe links an embedding's effective rank to downstream transfer; LiDAR refines rank assessment for joint-embedding architectures; rank-based measures also support model assessment in speech and audio; and geometric analyses of intrinsic dimension, anisotropy, and curvature reveal objective-dependent phase transitions across depth.

Music-specific observations exist too: Jukebox's intermediate layers peak on MIR tasks; MusicFM and MuQ show an acoustic-to-semantic trend across depth, with intermediate layers often beating weighted fusion; and on MERT and MusicGen, content attributes like pitch and chord root become more linearly accessible with depth while style attributes do not. Prior work here mostly relied on task-specific probing, targeted interventions, or post-hoc feature discovery rather than systematically characterizing representation geometry itself.

This paper's difference is being the first systematic layer-wise analysis of intrinsic representation properties across 12 music foundation models spanning three pretraining paradigms (masked modeling, autoregressive, contrastive), and the first to directly test whether these label-free metrics work as a practical layer-selection tool rather than staying at the level of observation.

方法Method

評測對象是 12 個音樂基礎模型,分三種預訓練典範:遮罩建模(MERT-95M/330M、MusicFM_MSD、MuQ_iter、OMAR-RQ,12 到 24 層、95M 到 580M 參數)、自迴歸(MusicGen-S/M/L、YuE-0.5B/7B,24 到 48 層、0.3B 到 7B 參數)、對比學習(LAION-CLAP、Myna-Base,12 到 21 層、22M 到 73M 參數)。所有模型凍結,表徵接一個 512 維隱藏層的淺層 MLP 去做 15 個下游任務(調性、節奏、音色、語意、相似度五大類),沿用 MARBLE 的受限賽道設定。

內在指標包含:內在維度(用 TwoNN 估計)、有效秩(RankMe,對奇異值分布算 Shannon 熵再取指數)、各向異性(最大奇異值平方佔總變異的比例)、時間曲率(相鄰時間步表徵位移向量的夾角期望值)、LiDAR(把原始片段當類別、增強視圖當同類樣本,算 LDA 矩陣的有效秩)、InfoNCE(對增強視圖的對比損失)。

最關鍵的新指標是「音高移調等變性」(PTE),改編自 STONE 的交叉功率頻譜密度目標:線性探針把序列層級嵌入映射到 12 維調性剖面(投影到五度圈上),同一個探針分別用在原始片段與升 k 個半音的版本上,若探針具備移調等變性,交叉功率的相位應該剛好是 -2πωk/12;論文用 10,000 段 MTG-Jamendo 音檔(70/15/15 切分)訓練,PTE 分數定義為 1 減去均方根和絃距離的一半,愈接近 1 代表 12 平均律的移調結構愈容易被解碼出來。

The evaluation covers 12 music foundation models across three pretraining paradigms: masked modeling (MERT-95M/330M, MusicFM_MSD, MuQ_iter, OMAR-RQ; 12–24 layers, 95M–580M parameters), autoregressive (MusicGen-S/M/L, YuE-0.5B/7B; 24–48 layers, 0.3B–7B parameters), and contrastive learning (LAION-CLAP, Myna-Base; 12–21 layers, 22M–73M parameters). All models stay frozen, with representations fed into a shallow MLP with a single 512-unit hidden layer for 15 downstream tasks across five families — tonal, rhythm, timbre, semantic, similarity — following MARBLE's constrained-track protocol.

The intrinsic metrics are: intrinsic dimension (estimated via TwoNN), effective rank (RankMe — the exponentiated Shannon entropy of the singular-value distribution), anisotropy (the fraction of total variance in the dominant singular direction), temporal curvature (the expected angle between consecutive representation-displacement vectors), LiDAR (treating each original clip as a class and its augmented views as within-class samples, then computing the effective rank of the resulting LDA matrix), and InfoNCE (a contrastive loss over augmented views).

The key new metric is pitch-transposition equivariance (PTE), adapted from STONE's cross-power spectral density objective: a linear probe maps a sequence-level embedding to a 12-dimensional key-signature profile projected onto the circle of fifths, and the same probe is applied to both the original clip and a version transposed up k semitones — an equivariant probe should show a cross-power phase of exactly -2πωk/12. Trained on 10,000 MTG-Jamendo clips (70/15/15 split), PTE is scored as 1 minus half the RMS chordal distance, with values near 1 meaning the 12-tone transposition structure is easily decoded.

限制Limitations

論文自己點名的限制是:這些指標與下游表現之間只是「相關」不是「因果」——「這些指標找出的是跟遷移能力較強相關聯的表徵特性,但並沒有證實直接去操弄這些特性就會改變下游表現」。訓練目標、監督方式、資料、架構、規模在現有模型之間本來就是糾纏在一起的,要真正拆解各自的貢獻需要做控制變因的預訓練實驗,而這篇沒有做。

部分指標本身就是「典範相依」的——像 LiDAR、InfoNCE 這類增強條件式的指標,原本就是針對特定訓練典範提出並驗證,拿到別的典範上可能失準;而且跨模型比較時,原始指標數值不能直接拿來比,因為架構本身異質性太高(有效秩的跨模型相關係數只有 0.02,幾乎跟哪一層最好無關),只有 PTE 在跨模型上仍然保有穩定的調性訊號。

The authors' own stated limitation is that the metrics are only correlational, not causal: "these metrics identify representation properties associated with stronger transfer, but do not establish whether directly manipulating them would affect downstream performance." Objective, supervision, data, architecture, and scale all co-vary across the models tested, and disentangling their individual contributions would require controlled pretraining experiments, which this paper does not run.

Some metrics are themselves paradigm-dependent — augmentation-conditioned metrics like LiDAR and InfoNCE were proposed and validated within specific training paradigms and may not transfer to others — and raw metric values are not directly comparable across architecturally heterogeneous models (effective rank's cross-model correlation with which layer is actually best drops to just 0.02). Only PTE retains a stable tonal signal across models.

討論Discussion

這篇論文最值得討論的地方,是它明確拆開了「一體適用」的幻覺:沒有任何單一內在指標可以同時預測所有 MIR 任務的表徵品質——語意任務靠內在維度,節奏任務靠曲率(愈平滑的時間軌跡遷移愈好),調性任務則非得靠論文自己造的 PTE 不可,標準的秩、維度指標在調性任務上幾乎失效。這種「按任務家族分工」的結論,比起宣稱找到一個萬用指標,誠實得多也更有操作性。

這套方法的實務價值在於把逐層 probing 需要跑的次數砍到四分之一到十六分之一,而且低資料量情境下(例如 GTZAN-Genre 只有 442 筆)所有需要訓練的融合方法都輸給 oracle 十個百分點以上,免訓練的 proxy-guided 方法反而穩得多——這對資源有限、無法把每個下游任務都跑一輪完整 probing 的研究者來說,是比再訓練一個更好的融合層更划算的路。

The most discussion-worthy part of this paper is how cleanly it dismantles the one-size-fits-all fantasy: no single intrinsic metric predicts representation quality across all MIR tasks — semantic tasks track intrinsic dimension, rhythm tasks track curvature (smoother temporal trajectories transfer better), and tonal tasks require the paper's own PTE metric, since standard rank and dimension metrics nearly fail there. A conclusion organized by task family is more honest and more actionable than claiming to have found one universal proxy.

The practical payoff is cutting the number of layer-wise probing runs needed by 4 to 16 times, and in low-data settings (GTZAN-Genre has only 442 clips) every trainable fusion method falls more than 10 percentage points behind the oracle while the training-free proxy-guided approach stays far more stable — a better use of limited compute than training yet another fusion layer, for researchers who can't afford to run full probing on every downstream task.

動機Motivation

現有的音樂人聲分離系統,不管是 Open-Unmix 這類基於時頻遮罩的模型,還是 Demucs 這種直接在原始波形上運作的編碼器-解碼器架構,都只把「人聲」當成單一分離目標:輸出的人聲軌是混音中所有歌手疊在一起的結果。這在獨唱情境下沒問題,但真實錄音裡二重唱、重唱很常見,多個歌手的音高與頻率會互相重疊,傳統模型無法把個別歌手分開,更遑論指定「只要某一位」。

作者把語音處理裡常見的目標語者萃取(target speaker extraction, TSE)概念搬過來:給一小段目標歌手的預錄音檔(enrollment)當條件,分離模型就只保留這位歌手,其餘歌手與伴奏一律當成干擾聲。他們點出三個難處:同時有乾淨獨唱與多人混音的資料集稀少、真實場景裡乾淨的單一歌手預錄音檔本來就難取得,以及歌聲在音高、音色、表現力上的變化比語音大得多。

Standard music vocal separation systems, whether mask-based ones like Open-Unmix or waveform encoder-decoder architectures like Demucs, treat "vocals" as a single target: the output vocal stem is whatever all singers together produced. That works for solo recordings, but duets and ensembles are common in real music, where multiple singers overlap in pitch and frequency and conventional models cannot isolate one singer from another, let alone extract a specific one on request.

The authors import target speaker extraction (TSE) from speech processing: a short enrollment recording of the target singer conditions the separation model to keep only that singer and treat everyone else, plus the accompaniment, as interference. They flag three obstacles: datasets pairing clean solo vocals with multi-singer mixtures are scarce, clean single-singer enrollment clips are hard to obtain in the wild, and singing varies more in pitch, timbre, and expression than speech does.

背景與相關研究Introduction & Prior Work

音樂人聲分離這條線上,Open-Unmix 靠時頻遮罩、Demucs 靠端到端波形建模,近期的 Moises-Light 與 Task-Aware Unified Source Separation 持續推進品質,但這些系統把人聲當成單一來源,MedleyVox、IdolSongsJP 這類多重唱分離(MSVS)基準資料集也只驗證「能不能把多個人聲切開」,切開之後哪一段屬於哪位歌手仍是盲的,選不出「這位」。

真正示範「用一小段登記音檔挑出目標對象」的是語音的目標語者萃取(TSE)家族:SpeakerBeam、VoiceFilter、SpEx+ 都是拿說話者嵌入去條件化分離網路,做法上不是對比學習就是從內部表徵取嵌入,再用特徵串接或 FiLM(feature-wise linear modulation)這類更靈活的方式把嵌入注入分離模型。

這篇論文老實說沒有提出新的分離機制或新的條件化手段——串接與 FiLM 都是 TSE 文獻裡已經在用的做法,骨幹分離網路直接沿用 Open-Unmix。它的貢獻是把這整套「登記音檔 + 嵌入條件化」的組合,從語音領域原封不動搬到歌聲分離,並且證明搬過來之後在二重唱場景真的能用。

On the music side, Open-Unmix relies on time-frequency masking and Demucs on end-to-end waveform modeling, with recent systems like Moises-Light and Task-Aware Unified Source Separation pushing quality further, but all of them treat vocals as one source. Benchmark datasets for multi-singer separation, MedleyVox and IdolSongsJP, only test whether singers can be split apart, not which split belongs to which singer — the output stays blind to identity.

The actual precedent for "use a short enrollment clip to pick a target" comes from speech: target speaker extraction (TSE) methods SpeakerBeam, VoiceFilter, and SpEx+ already condition a separation network on a speaker embedding, obtained via contrastive learning or from internal representations, and inject it through feature concatenation or the more flexible FiLM (feature-wise linear modulation).

This paper does not introduce a new separation mechanism or a new conditioning trick — concatenation and FiLM are both established TSE techniques, and the backbone separator is Open-Unmix unchanged. The contribution is porting the entire "enrollment clip plus embedding conditioning" recipe from speech to singing voice separation and showing it works in duet mixtures.

方法Method

分離模型分兩塊:一是歌手嵌入模型,用兩層 GRU(隱藏層 32 維)吃登記音檔的振幅頻譜圖,取最後一個隱藏狀態當固定維度的嵌入,訓練時用對比學習拉近同一歌手、拉遠不同歌手;二是以 Open-Unmix 為骨幹的分離網路,一樣吃振幅頻譜圖、輸出頻譜遮罩,但把歌手嵌入用兩種方式之一注入:沿時間重複後直接與輸入特徵串接,或是用 FiLM 對中間層特徵做逐元素的縮放與平移調變(FiLM(h, z) = γ(z)⊙h + β(z))。

訓練用 6 秒片段,Adam 最佳化器,學習率 1e-3,權重衰減 1e-5,主要損失是尺度不變訊噪比(SI-SDR),部分版本另外加一個監督殘餘訊號(其他歌手加伴奏)的雙重損失項。

The system has two parts: a singer embedding model — a two-layer GRU with hidden size 32 — that reads the enrollment clip's magnitude spectrogram and takes the final hidden state as a fixed-size embedding, trained contrastively so same-singer embeddings pull together and different-singer ones push apart; and an Open-Unmix-backbone separator that reads the mixture's magnitude spectrogram and predicts a spectral mask, injecting the singer embedding either by repeating it across time and concatenating with input features, or via FiLM, which scales and shifts intermediate features per element (FiLM(h, z) = γ(z)⊙h + β(z)).

Training uses 6-second segments, Adam at learning rate 1e-3 with weight decay 1e-5, and a scale-invariant SDR (SI-SDR) loss, with some variants adding a dual loss term that also supervises the residual signal (other singers plus accompaniment).

限制Limitations

論文自己承認的未來方向已經點出限制所在:目前只處理最多兩位歌手(二重唱),沒有驗證三人以上的合唱;登記音檔假設是乾淨、只含目標歌手的錄音,現實中要找到這種素材本身就是論文開頭點名的三個難題之一,等於方法論成立的前提還沒被方法本身解決。

測試集只有 559 首原始二重唱錄音,規模偏小。獨唱情境下基準模型(未條件化的 Open-Unmix)反而拿下最高分(人聲 17.80 dB、伴奏 16.68 dB)——這說明條件化機制在不需要挑選目標時沒有帶來好處,只是不需要用而已,但也代表這套機制目前無法在「不知道現場有幾位歌手」的通用場景裡自動判斷該不該啟用。

The paper's own future-work list points at where it falls short: only two-singer duets are handled, with no validation on ensembles of three or more; enrollment clips are assumed to be clean recordings containing only the target singer, which is exactly one of the three obstacles the paper opens by naming, so the method's own precondition remains unsolved by the method itself.

The test set covers only 559 original duet recordings, a modest scale. In the solo setting, the unconditioned Open-Unmix baseline scores highest (17.80 dB vocal, 16.68 dB background) — conditioning brings no benefit when there is nothing to select against, but it also means the system has no built-in way to decide whether to engage at all in a general setting where the number of singers present is unknown.

討論Discussion

這篇論文最值得討論的地方不是分離效果本身,而是它把「登記音檔式條件化」這套語音領域已經成熟的做法,幾乎原封不動地驗證了一次可以套用到歌聲上——這比發明新架構更接近工程驗證的性質。

它也暴露一個評估框架上的問題:把「未條件化的通用分離模型」當作目標歌手萃取任務的基準線,本質上是拿一個沒被要求做這件事的系統來比較,0.33 dB 到 5.58 dB 的落差有多少是「條件化真的有效」、多少只是「基準線的任務設定本來就不對」,論文沒有拆開來談。FAD 從基準線 2.28 降到最佳模型 0.37,是比 SI-SDR 更能說服人的證據,因為它衡量的是感知層面的音色貼近程度,而不只是訊號重建誤差。

The most discussion-worthy aspect here isn't the separation quality itself but the fact that this is essentially an engineering validation — porting an already-mature speech-domain technique, enrollment-conditioned extraction, onto singing with minimal modification, rather than a new architectural idea.

It also exposes a framing issue in the evaluation: using an unconditioned general-purpose separator as the baseline for a target-singer extraction task compares against a system that was never asked to do this job, and the paper never separates how much of the 0.33-to-5.58 dB gap reflects genuine conditioning benefit versus a mismatched baseline task. The FAD drop from 2.28 (baseline) to 0.37 (best model) is more persuasive than the SI-SDR numbers, since it captures perceptual timbral closeness rather than just signal-reconstruction error.

為什麼挑這篇：既有的音訊效果（Fx）表徵學習方法幾乎都假設可以拿到乾聲（未經處理）的參考音訊，但真實錄音裡根本不存在真正未經處理的聲音——麥克風跟錄音空間本身就會留下痕跡，這也是為什麼訓練資料只能侷限在MUSDB18這類少數的多軌資料集。RelFx換一個角度：不去學「這段音訊的效果狀態是什麼」這種絕對表徵，而是學「從一段音訊到另一段音訊之間的效果轉換距離」這種相對表徵，讓訓練不再需要乾聲參考，可以直接用任何一對「同來源、不同效果處理」的音訊片段訓練。方法本身是把既有的對比學習、雙分支CNN、交叉注意力等常見元件組合起來解決一個特定問題，沒有全新的架構突破，因此不列為深度分析；但它解除了Fx表徵學習長期依賴乾聲資料集的限制，同時額外設計了一個「反對稱」變體讓E(A,B)≈−E(B,A)成立，是紮實的表徵學習工作。Why this one: Existing audio effects (Fx) representation learning methods almost universally assume access to dry (unprocessed) reference audio, but truly unprocessed audio doesn't really exist in real recordings — the microphone and recording space leave their own trace, which is also why training data has been confined to a handful of multitrack datasets like MUSDB18. RelFx takes a different angle: rather than learning an absolute representation of "what effect state is this audio in," it learns a relative representation of "the effect-transformation distance from one audio clip to another," so training no longer needs dry references at all and can run directly on any pair of "same-source, differently-processed" clips. The method itself combines existing components — contrastive learning, a dual-branch CNN, cross-attention — to solve a specific problem, without a genuinely new architecture, so it isn't flagged as a deep dive; but it removes Fx representation learning's long-standing dependence on dry-reference datasets, and additionally designs an antisymmetric variant making E(A,B)≈−E(B,A) hold, making it solid representation-learning work.

動機Motivation

等化、破音、壓縮、殘響這些音訊效果是音樂製作的核心工具，能不能學出一個好用的Fx表徵，直接關係到Fx風格轉移、自動混音等下游應用的成效。但作者指出既有的Fx表徵學習方法有一個共同的結構性前提：需要一段乾聲（未經處理）的參考音訊當比較基準，才能定義出「這段音訊被加了什麼效果」這個絕對狀態。這個前提在實務上有三個問題：第一，真實錄音裡根本沒有真正的乾聲——麥克風特性、錄音空間的殘響，這些都已經是某種形式的「處理」；第二，同時擁有乾聲跟處理後版本的資料集非常稀少，訓練資料被侷限在MUSDB18這類有限的多軌資料集裡；第三，「絕對狀態」這個框架天生只支援單向建模（從某段音訊推斷它的效果狀態），沒辦法自然地表達「從A到B要怎麼調整」這種混音師實際思考問題的方式——混音工程師在工作時，想的通常是「這個聲音現在聽起來像這樣，我要把它調成聽起來像那樣」的相對距離，而不是抽象的絕對效果標籤。

Equalization, distortion, compression, and reverb are core tools of music production, and how good an Fx representation can be learned bears directly on downstream tasks like Fx style transfer and automatic mixing. The authors point out that existing Fx representation-learning methods share a structural assumption: they need a dry (unprocessed) reference audio as a comparison baseline to define the absolute state of "what effect has been applied to this audio." This assumption creates three practical problems. First, truly dry audio doesn't exist in real recordings — microphone characteristics and room reverb are already a form of processing. Second, datasets pairing dry and processed versions of the same audio are scarce, confining training data to a handful of multitrack sets like MUSDB18. Third, the absolute-state framing inherently supports only one-directional modeling (inferring a clip's effect state), and can't naturally express how a mixing engineer actually reasons — thinking in terms of "this sound is here, I want it to sound like that" as a relative distance, not an abstract absolute label.

背景與相關研究Introduction & Prior Work

論文把相關研究放在兩塊。第一是智慧音樂製作裡的應用：Fx風格轉移希望透過可微分訊號處理、盲參數估計、端對端神經網路等手段，捕捉一段參考訊號的音色特徵並套用到另一段訊號上；自動混音則是平衡多軌音訊的音量與音色。這兩個任務都仰賴一個好用的Fx表徵當基礎。第二是既有的Fx表徵學習方法：AFx-Rep靠效果與預設分類的方式學表徵、Fx-Encoder用對比學習學混音層級的表徵、Fx-Encoder++則進一步做到樂器層級的嵌入抽取；另外VGGish、CLAP這類通用音訊表徵雖然能用，但顆粒度不夠細，抓不住效果專屬的細節。這些方法無一例外都建立在「絕對效果狀態」的框架上，而RelFx要做的，正是把這整個框架換成「相對轉換」。

The paper situates related work in two areas. First, applications in intelligent music production: Fx style transfer aims to capture a reference signal's timbral characteristics and apply it to another signal via differentiable signal processing, blind parameter estimation, or end-to-end neural networks; automatic music mixing balances multi-track audio levels and timbre. Both tasks depend on a solid Fx representation as their foundation. Second, existing Fx representation learning: AFx-Rep learns representations via effect-and-preset classification, Fx-Encoder uses contrastive learning for mixture-level representations, and Fx-Encoder++ extends this to instrument-wise embedding extraction; general-purpose audio representations like VGGish and CLAP are usable but too coarse-grained to capture effect-specific detail. Every one of these methods is built on the absolute-effect-state framework, and RelFx's move is to replace that entire framework with relative transformation instead.

方法Method

問題設定：不去學絕對表徵E(x)→z，而是給定參考片段x、來源片段x'、效果變換θ，處理後的來源片段是x̃=Fx(x';θ)，編碼器直接吃(x, x̃)這個有序配對：z=E(x,x̃)=E(x,Fx(x';θ))。兩段輸入都不需要先做乾聲或效果標準化的前處理。對比目標鼓勵「同一種變換套用在不同內容上」得到相近的嵌入：d(z_a(θ),z_b(θ))≪d(z_a(θ),z_c(θ'))。

模型架構：頻譜前端用log-mel頻譜，STFT設定nfft=2048、hop size=512、64個mel頻帶。骨幹是CNN14風格的孿生（Siamese）CNN，六個卷積階段，通道數依序為[64,128,256,512,1024,2048]，兩個分支共享權重。在第3階段（256通道）與第5階段（1024通道）之後各插入一次雙向交叉注意力（4個頭、4×4空間池化、殘差縮放係數α=0.1）：h'_ref=h_ref+α·CrossAttn(h_ref,h_proc)。

差異門控融合（基礎模型）：全域池化後得到e_ref、e_proc∈ℝ^2048，融合方式是e_fx=g⊙(e_proc−e_ref)+(1−g)⊙e_proc，其中g=σ(W[e_ref;e_proc]+b)。差異項捕捉相對變化，絕對項保留內容特徵。

反對稱（雙向相容）變體：為了讓E(A,B)≈−E(B,A)這個反對稱性質成立，融合方式改成e_fx=g⊙(e_proc−e_ref)，g=σ(W(e_ref+e_proc)+b)——門控值本身對輸入順序不敏感，但差異項在交換輸入時會自動變號。投影頭是兩層MLP，映到128維並做L2正規化；基礎模型用ReLU，反對稱變體用tanh以保留符號翻轉的性質。

訓練資料準備：每個訓練樣本從同一首歌的同一個段落裡取兩段不重疊的片段(x_q,x'_q)，套用同一組效果設定θ；跨段落取樣（用同一結構段落內相鄰、不重疊的片段）刻意用來避免模型抄「內容捷徑」。內容相似度分析顯示，同段落相鄰片段在Fx-Encoder++嵌入空間下的平均餘弦相似度是0.938，跨曲則只有0.684，說明這個取樣策略確實把「內容相似」跟「效果相同」這兩件事分開了。

效果鏈設計：八種依序串接的效果——等化器、破音、多頻段壓縮器、增益、立體聲成像、限幅器、延遲、殘響——共72個連續參數與8個二元開關，效果順序在每個批次內隨機打亂。動態效果機率排程：每種效果被啟用的機率會根據該效果目前的訓練損失動態調整——損失較高（代表模型還沒學好）的效果，下一輪會被更頻繁地抽到，機率被限制在[0.3,0.8]之間。

損失函數：ℒ=ℒ_ctr+λ_tℒ_triplet+λ_pℒ_param。對比損失是修改版的NT-Xent（溫度τ=0.15），正樣本的logit在分母裡重複計算兩次：ℒ_ctr=−(1/2N)Σlog(e^{s_i,p(i)}/(2e^{s_i,p(i)}+Σe^{s_ik}))。三元組損失（間距m=0.3）：ℒ_triplet=(1/N)Σmax(0,d(z_a_i,z_b_i)−d(z_a_i,z_neg_i)+m)。參數回歸損失強制嵌入空間帶有連續結構：ℒ_param=MSE_masked(p̂,p)+λ_a·BCE(â,a)。超參數設定為λ_t=0.5、λ_p=0.5、λ_a=0.3、τ=0.15、m=0.3。

訓練資料與設定：6,447段混音音軌（2,681首歌、185.9小時）加上來自MoisesDB的2,585段音軌（240首歌、156.4小時）；每段10秒立體聲、44.1kHz取樣；依歌曲ID切分85%/15%訓練/驗證集；4張NVIDIA L20 GPU訓練200個epoch，每GPU批次大小48，梯度累積4步（有效批次大小768）；AdamW優化器，學習率5×10⁻⁴，權重衰減10⁻⁵，10個epoch線性暖身後餘弦退火到10⁻⁶。

Problem formulation: rather than learning an absolute representation E(x)→z, given reference clip x, source clip x', and effect transformation θ, the processed-source clip is x̃=Fx(x';θ), and the encoder takes the ordered pair (x, x̃) directly: z=E(x,x̃)=E(x,Fx(x';θ)). Neither input requires dry or effect-normalized preprocessing. The contrastive objective encourages the same transformation applied to different content to yield similar embeddings: d(z_a(θ),z_b(θ))≪d(z_a(θ),z_c(θ')).

Model architecture: the spectrogram frontend uses log-mel spectrograms, STFT with nfft=2048, hop size 512, 64 mel bins. The backbone is a CNN14-style Siamese CNN with six convolutional stages, channel dimensions [64,128,256,512,1024,2048], weights shared across branches. Bidirectional cross-attention is inserted after stages 3 (256 channels) and 5 (1024 channels), 4 heads, 4×4 spatial pooling, residual scale α=0.1: h'_ref=h_ref+α·CrossAttn(h_ref,h_proc).

Differential gating fusion (base model): after global pooling yields e_ref, e_proc∈ℝ^2048, fusion is e_fx=g⊙(e_proc−e_ref)+(1−g)⊙e_proc, where g=σ(W[e_ref;e_proc]+b). The differential term captures relative change while the absolute term retains content characteristics.

Antisymmetric (bidirectional-compatible) variant: to make E(A,B)≈−E(B,A) hold, fusion changes to e_fx=g⊙(e_proc−e_ref), g=σ(W(e_ref+e_proc)+b) — the gate itself is order-insensitive, while the differential term automatically flips sign when inputs are swapped. The projection head is a two-layer MLP to a 128-dimensional L2-normalized embedding; the base model uses ReLU, the antisymmetric variant uses tanh to preserve the sign-reversal property.

Training data preparation: each training item samples two non-overlapping clips (x_q, x'_q) from the same section of the same song, applying one shared effect configuration θ; cross-segment sampling (adjacent, non-overlapping clips within one structural section) is deliberately used to discourage content-based shortcuts. Content similarity analysis shows same-section adjacent clips have a mean cosine similarity of 0.938 in Fx-Encoder++ embedding space, versus only 0.684 across different songs — confirming this sampling strategy genuinely decouples "similar content" from "same effect."

Effects chain design: eight sequentially chained effects — equalizer, distortion, multiband compressor, gain, stereo imager, limiter, delay, reverb — with 72 continuous parameters and 8 binary switches, effect order randomized per batch. Dynamic Fx probability scheduling: each effect's activation probability is adaptively adjusted based on its running training loss — effects with higher residual loss (meaning the model hasn't learned them well yet) get sampled more frequently next epoch, clamped to [0.3, 0.8].

Loss function: ℒ=ℒ_ctr+λ_tℒ_triplet+λ_pℒ_param. The contrastive loss is a modified NT-Xent (temperature τ=0.15) with the positive logit counted twice in the denominator: ℒ_ctr=−(1/2N)Σlog(e^{s_i,p(i)}/(2e^{s_i,p(i)}+Σe^{s_ik})). The triplet loss (margin m=0.3): ℒ_triplet=(1/N)Σmax(0,d(z_a_i,z_b_i)−d(z_a_i,z_neg_i)+m). A parameter regression loss enforces continuous structure in embedding space: ℒ_param=MSE_masked(p̂,p)+λ_a·BCE(â,a). Hyperparameters: λ_t=0.5, λ_p=0.5, λ_a=0.3, τ=0.15, m=0.3.

Training data and setup: 6,447 mixed tracks (2,681 songs, 185.9 hours) plus 2,585 stems from MoisesDB (240 songs, 156.4 hours); 10-second stereo clips at 44.1kHz; split 85%/15% train/validation by song ID; 200 epochs on 4× NVIDIA L20 GPUs, batch size 48 per GPU with 4-step gradient accumulation (effective batch size 768); AdamW at learning rate 5×10⁻⁴, weight decay 10⁻⁵, 10-epoch linear warmup then cosine annealing to 10⁻⁶.

Baselines: Fx-Encoder++, AFx-Rep, VGGish, CLAP.

Evaluation task 1: Fx style transfer: embedding-guided gradient optimization adjusts a differentiable effect chain's parameters so the output audio's embedding approaches a reference embedding; 7 random restarts per sample with Adam (learning rate 10⁻², up to 200 iterations, patience 50); 100 samples per instrument drawn from MUSDB18, with median multi-resolution STFT loss L_d as the primary metric (lower is better).

The Standard configuration achieves the lowest overall average L_d. Improvements over Fx-Encoder++: drums 16.7%, bass 16.2%, vocals 12.5%, other 7.9%, averaging 13.3%. Trained only on MoisesDB (matching Fx-Encoder++'s training data), RelFx reaches 1.449 versus Fx-Encoder++'s 1.601, a 9.5% improvement.

Evaluation task 2: effects retrieval ablation (Table 3): given a processed query clip, retrieve candidates with the identical effect but different content from a pool of 500, measured via Recall@K (K=1,5,10) and L_d. Full model: R@1=67.3, R@5=79.2, R@10=83.7, L_d=1.399. Removing cross-attention: R@1=65.6, R@5=78.2, R@10=82.8, L_d=1.392 (retrieval slightly worse, L_d slightly better). Removing parameter regression: R@1=70.4, R@5=81.7, R@10=85.5, L_d=1.437 (L_d up 2.7%). Removing dynamic Fx probability scheduling: R@1=71.7, R@5=79.8, R@10=83.3, L_d=1.465 (L_d up 4.7%). Single-branch configuration: R@1=46.1, R@5=62.6, R@10=68.8, L_d=1.457 (L_d up 4.1%, confirming the dual-branch design carries real value).

Composition cos(E_AB+E_BC,E_AC) — bidirectional variant: drums 0.849, vocals 0.834, average 0.842; base variant: drums 0.798, vocals 0.742, average 0.770. 限制Limitations

作者自己承認的限制是：這套方法建模的是「整體」轉換，沒有辦法把混音裡各個獨立音軌各自被套用的效果分開處理——換句話說，如果輸入是一段完整混音，模型學到的相對距離是整體混音層級的轉換，無法回答「鼓組上加了什麼效果、人聲上又加了什麼效果」這種樂器層級的細部問題。另外，論文明確承認「未見過的效果鏈順序」跟「真實世界的混音製作鏈」都還沒有被驗證過——訓練時效果順序雖然有隨機打亂，但測試時是否能推廣到訓練時完全沒見過的效果排列組合、或是實際錄音室工作流程裡更複雜的效果串接方式，都被列為未來工作，目前的實驗結果沒有直接回答這個問題。

The authors' own acknowledged limitation is that the method models overall transformations rather than separating out effects applied to individual sources within a mixture — given a full mix as input, the learned relative distance operates at the mixture level and can't answer instrument-specific questions like "what was applied to the drums versus the vocals." The paper also explicitly notes that unseen effect-chain orderings and real-world production chains remain unvalidated — while training randomizes effect order, whether the model generalizes to effect combinations never seen during training, or to the more elaborate effect chains used in actual studio workflows, is left as future work and isn't directly answered by the current experiments.

討論Discussion

這篇論文最有意思的地方，是把「跨段落取樣消融」這個看似邊緣的設計選擇，變成了整篇論文論證最有力的一組數字：拿掉跨段落取樣後，效果檢索的Recall@K指標全部小幅上升，但風格轉移的L_d卻暴增34%。這個「一好一壞」的反差正好揭穿了一個容易被忽略的陷阱——如果訓練時允許模型從同一個片段裡直接切出正樣本對，模型很容易學到「內容相似度」而不是「效果轉換」這個真正該學的訊號，而「效果檢索」這個任務剛好對這種捷徑不敏感（甚至因為內容線索而表現更好），只有像風格轉移這種真正需要用嵌入去驅動梯度優化的下游任務，才會把這個捷徑的破壞力暴露出來。這說明了論文選擇風格轉移當主要評估指標、而不是只看檢索指標，是一個經過深思熟慮的方法論決定。反對稱變體的結果也呼應了同一個主題：−0.998的近乎完美符號翻轉，證明只要在架構設計裡把「差異項」跟「內容項」明確拆開（用tanh而非ReLU、把絕對項從最終融合公式裡拿掉），相對表徵確實可以帶有代數上一致的方向性，這對後續想要做「效果空間裡的向量運算」（比如把A的殘響量減掉、加上B的殘響量）這類應用開了一個口子。整體而言，RelFx沒有提出全新的架構元件，但它精準地找到了「絕對表徵框架依賴乾聲」這個現實限制，換了一個問題定義方式把它繞開，並且用消融實驗把「為什麼要這樣設計」的每一個決定都量化驗證了一遍，是紮實但不追求架構新穎性的表徵學習工作。

The paper's most interesting move is turning what looks like a peripheral design choice — the cross-segment-sampling ablation — into its most compelling piece of evidence: removing cross-segment sampling makes every effects-retrieval Recall@K metric tick slightly up, while style-transfer L_d spikes 34%. That "one metric improves while the other collapses" contrast exposes an easy-to-miss trap: if training allows positive pairs cut directly from the same clip, the model readily learns "content similarity" instead of the effect transformation it's actually supposed to capture, and effects retrieval happens to be insensitive to this shortcut (even benefiting from the content cue) — only a downstream task like style transfer, which genuinely needs the embedding to drive gradient optimization, exposes how damaging that shortcut is. This shows the paper's choice of style transfer as its primary evaluation metric, rather than retrieval alone, was a deliberate methodological decision. The antisymmetric variant's results echo the same theme: near-perfect sign reversal at −0.998 confirms that explicitly separating the differential term from the content term in the architecture (tanh instead of ReLU, dropping the absolute term from the final fusion) does let the relative representation carry algebraically consistent directionality — opening the door to applications like vector arithmetic in effect space (subtract A's reverb amount, add B's). Overall, RelFx introduces no fundamentally new architectural component, but it precisely identifies the real-world constraint that the absolute-representation framework depends on dry references, sidesteps it with a reframed problem definition, and quantifies every design decision through ablations — solid representation-learning work that doesn't chase architectural novelty.

MAJEPPA: Morphing and Assessing in a Unified Piano Performance Space

MAJEPPA：在統一鋼琴演奏空間中同時做形變與評估

Jinwen Zhou, Huan Zhang, Weixi Zhai, Jinhua Liang, Aidan O. T. Hogg, Simon Dixon
arXiv:2608.11026 · eess.AS, cs.MM · 投稿submitted 2026-08-11
abspdfhtmlcited by
為什麼挑這篇：現有鋼琴演奏理解研究把「風格」「準確度」「表現力」「技巧偵測」當成互相獨立的任務分開做，資料也幾乎只收錄職業級演奏，兒童初學者的錄音幾乎不存在。這篇論文蒐集了橫跨六種程度（兒童初學到大師）與六種錄音情境（練習到音樂會）共約4,000段錄音，並把JEPA（Joint-Embedding Predictive Architecture，先前只用在影像與影片上）第一次搬進符號音樂的樂譜—演奏配對，用同一個表徵空間同時支援生成與抽象評估。它老實報告了生成能力「因時間不足沒有完整評估」，這種公開留白比包裝完美的結果更值得记录。Why this one: Existing piano-performance research treats style, accuracy, expressivity, and technique detection as separate tasks, and almost all training data comes from professional recordings, leaving child-beginner practice all but absent. This paper assembles roughly 4,000 recordings spanning six expertise levels (child beginner to virtuoso) and six recording contexts (practice to concert), and is the first to bring JEPA (Joint-Embedding Predictive Architecture, previously applied only to images and video) into symbolic music's score-performance pairs, using one shared representation space for both generation and abstract assessment. It's flagged as a deep dive partly because the authors candidly admit generation quality was never fully evaluated due to time constraints — an honest gap that's more useful than a polished-looking result would be.

動機Motivation

鋼琴演奏橫跨從兒童初學者到職業音樂會演奏家的完整光譜，但既有系統把「這段演奏彈得好不好」「跟哪位鋼琴家的風格接近」「用了什麼演奏技巧」「有沒有彈錯音」當成彼此獨立的任務，各自訓練各自的模型。作者認為這種切分是本末倒置：一個統一的演奏表徵才是更根本的東西，各種高層次判斷應該是從這個表徵裡「衍生」出來，而不是分別學習。要建立這樣的表徵，必須先解決兩個缺口。第一個是資料缺口：現有的符號演奏資料集幾乎全部只收錄職業演奏，初學者、練習中途、帶錯誤的演奏幾乎沒有被系統性蒐集過，但這些「不完美」的演奏正是評估系統最需要理解的對象。第二個是方法缺口：目前沒有任何框架能同時捕捉「抽象的演奏特徵」（風格、準確度、表現力）並把它跟對應的樂譜連結起來——大部分模型要嘛只做重建式的遮罩預訓練，要嘛只做生成，沒有一個框架把「評估」與「生成」放在同一個表徵裡處理。

Piano performance spans a full spectrum from child beginners to professional concert virtuosi, yet existing systems treat questions like "how good is this performance," "whose style does it resemble," "what technique was used," and "were there mistakes" as separate tasks, each trained in isolation. The authors argue this division has things backwards: a unified representation of performance is the more foundational object, and these higher-level judgments should be derived from it rather than learned independently for each task. Building such a representation requires closing two gaps. The first is a data gap: existing symbolic performance datasets focus almost exclusively on professional recordings, leaving beginner practice, mid-session mistakes, and imperfect playing — exactly what an assessment system most needs to understand — essentially uncollected. The second is a methodological gap: no existing framework simultaneously captures abstract performance characteristics (style, accuracy, expressivity) while linking them to the underlying score; most models either do reconstruction-based masked pretraining or pure generation, with none placing assessment and generation in the same representation space.

背景與相關研究Introduction & Prior Work

論文把相關研究分成兩條線。第一條是音樂表徵學習：遮罩重建式的方法如MusicBERT、MidiBERT-Piano學習局部結構；自迴歸基礎模型如Moonbeam（規模達18B參數）著重生成能力；CLaMP 3之類的跨模態對齊方法把音樂與文字或圖片連結起來。但這些方法對「演奏層級」的理解——同一份樂譜被不同程度的演奏者彈奏後產生的差異——仍然零散地分散在各自獨立的研究裡，沒有整合。第二條是JEPA（Joint-Embedding Predictive Architecture）：這個架構的核心想法是不透過像素或token級的重建去學表徵，而是直接在潛在空間裡從「部分上下文」預測「目標的潛在表示」，藉此逼迫模型學到抽象、語意層級的結構而非表面細節。I-JEPA把這個想法用在影像上，V-JEPA 2延伸到影片，兩者都證明了預測潛在表示比逐像素重建更能學到有用的抽象特徵。這篇論文的關鍵洞察是：樂譜與演奏正好構成一組天然的「兩個視角」——樂譜是抽象的意圖，演奏是具體的實現——非常適合套用JEPA的預測框架，但截至目前沒有人把JEPA用在符號音樂的樂譜-演奏配對上。

The paper divides related work into two threads. The first is music representation learning: masked-reconstruction methods like MusicBERT and MidiBERT-Piano learn local structure; autoregressive foundation models such as Moonbeam (scaling to 18B parameters) emphasize generation; and cross-modal alignment approaches like CLaMP 3 connect music to text or images. But performance-level understanding — how the same score played by musicians of different skill produces different results — remains scattered across isolated studies rather than integrated into one framework. The second thread is JEPA (Joint-Embedding Predictive Architecture): its core idea is to learn representations not through pixel- or token-level reconstruction but by predicting a target's latent representation directly from partial context in latent space, forcing the model toward abstract, semantically meaningful structure rather than surface detail. I-JEPA applied this to images and V-JEPA 2 extended it to video, both showing that predicting latents beats pixel-wise reconstruction for learning useful abstractions. The paper's key insight is that score and performance naturally form a two-view pair — the score is abstract intent, the performance is concrete realization — an ideal fit for JEPA's predictive framework, yet no prior work had applied JEPA to symbolic music's score-performance pairs.

方法Method

資料集構建：團隊蒐集了3,979段錄音、涵蓋942首曲目，共303.2小時，橫跨六種程度（兒童初學、兒童專業、成人初學、成人中階、鋼琴教師、大師）與六種錄音情境（練習、視奏、展演、示範、慢速示範、音樂會）。錄音來源是YouTube上的教學頻道、教程影片與比賽錄影，並由音樂院的標註者用校準文件與參照片段手動標籤。處理流程包含：長影片的斷點分段、用Transkun把音訊轉成MIDI、用子序列動態時間校正（subsequence DTW）對齊樂譜與演奏（處理彈錯、漏彈、重複段落等狀況）、最後切成固定長度的視窗。

模型架構：核心想法是把樂譜與演奏視為同一份音樂內容的兩個互補視角，模型學習在共享的潛在空間裡從樂譜表示預測演奏表示。以Aria-medium（632M參數）作為骨幹，凍結原本權重、加上LoRA微調（7500萬可訓練參數），用單一[PRED\]預測token透過綁定自注意力機制運作，並加入類別條件token（[COND_X]代表演奏者、[COND_Y]代表錄音情境），再接一個512維投影頭做對比學習。

雙通道訓練：Pass 1用因果遮罩，是標準的自迴歸生成——演奏token可以看到完整的前文，讓模型學會依樂譜生成演奏；Pass 2用區塊對角遮罩實現JEPA目標——樂譜視角與演奏視角彼此看不到對方，強迫模型只能從樂譜抽象地預測演奏,而不是靠捷徑對齊。

損失函數由四項組成：ℒ = γℒ_gen + λ(ℒ_piece + βℒ_cond + αℒ_self)，其中ℒ_gen是演奏token的下一個token交叉熵、ℒ_piece是InfoNCE損失把預測出的樂譜嵌入對齊到配對的演奏嵌入、ℒ_cond是用條件標籤間連續相似度做的軟性監督對比損失、ℒ_self是同一段演奏不同片段間的對稱InfoNCE。訓練用4張A100-80GB跑120個epoch,批次大小32(每GPU 8,梯度累積4),透過線性RoPE縮放把上下文窗口擴充到4096個token。

評估基準EVPMR涵蓋五類下游任務：演奏評分回歸(NeuroPiano、YCU-PPE-III、PISA三個資料集)、蕭邦鋼琴大賽初賽排名(130場演奏的配對排名)、七類技巧偵測、八位鋼琴家身分辨識(Pianist8)、以及無參照錯誤偵測(UMP,在三個資料集上做token級的明顯錯誤偵測)。所有任務都用凍結的表徵接線性探測器評估。

Dataset construction: The team assembled 3,979 recordings across 942 pieces (303.2 total hours), spanning six expertise levels (child beginner, child professional, adult beginner, adult intermediate, piano teacher, virtuoso) and six recording contexts (practice, sight-reading, showcase, demo, slow demo, concert). Recordings were sourced from pedagogical YouTube channels, tutorial videos, and competition footage, and manually labeled by conservatoire-trained annotators using calibration documents and reference clips. The processing pipeline includes breakpoint segmentation of long videos, audio-to-MIDI transcription via Transkun, subsequence dynamic time warping to align score and performance (handling mistakes, omissions, and repeats), and fixed-length windowing for model input.

Model architecture: The core idea treats score and performance as two complementary views of the same musical content, with the model learning to predict performance representations from score representations in a shared latent space. It builds on an Aria-medium backbone (632M parameters), frozen with LoRA adaptation (75M trainable parameters), using a single [PRED] token operating via tied self-attention, plus categorical conditioning tokens ([COND_X] for performer, [COND_Y] for recording context) and a 512-dimensional projection head for the contrastive objectives.

Two-pass training: Pass 1 uses a causal mask for standard autoregressive generation — performance tokens attend to the full preceding context, teaching the model to generate performance from score. Pass 2 uses a block-diagonal mask for the JEPA objective — score view and performance view cannot see each other, forcing the model to predict abstractly from score alone rather than taking an alignment shortcut.

The training loss combines four terms: ℒ = γℒ_gen + λ(ℒ_piece + βℒ_cond + αℒ_self), where ℒ_gen is next-token cross-entropy over performance tokens, ℒ_piece is an InfoNCE loss aligning the predicted score embedding with its paired performance embedding, ℒ_cond is a soft supervised-contrastive loss using continuous similarity between condition tags, and ℒ_self is a symmetric InfoNCE over segments of the same performance. Training runs on 4x A100-80GB GPUs for 120 epochs, batch size 32 (8 per GPU, gradient accumulation 4), with the context window extended to 4096 tokens via linear RoPE scaling.

The EVPMR benchmark covers five downstream task categories: performance-quality regression (NeuroPiano, YCU-PPE-III, PISA), Chopin Competition preliminary-round ranking (pairwise ranking over 130 performances), 7-way technique detection, 8-way pianist identification (Pianist8), and unreferenced mistake prediction (token-level detection of conspicuous mistakes across three datasets). All tasks are evaluated with linear probes on frozen representations.

限制Limitations

作者自己列出了幾個限制。第一，生成能力的評估不完整：論文承認「因時間限制,沒有對生成能力做完整評估」，只把樣本與互動式展示放到補充網站上,沒有系統性的量化結果——這代表雙通道架構裡負責生成的那一半,其實際輸出品質尚未被嚴謹檢驗過。第二,轉譜品質未經查核：Transkun雖被稱為「音符層級的最先進方法」,但作者「沒有明確檢查轉譜品質(包含踏板痕跡)」,意味著資料標籤本身可能帶有未知的轉譜誤差。第三,踏板處理的侷限：Aria的tokenizer沒有明確的踏板token(延音被折疊進音符時長裡),所以跟Aria基線的比較沒辦法把踏板這個獨立的表現線索單獨隔離出來評估。第四,資料權利的隱憂:雖然影片是公開可得的,但上傳者原本擁有的權利並未被放棄,作者承諾若被要求會移除相關內容,這代表資料集的長期可用性存在不確定性。整體而言,這篇論文的核心賣點(表徵學習)驗證得相當扎實,但配套的生成能力幾乎是空白,讀者不該把「JEPA表徵學得好」直接推論成「這個系統也能生成高品質演奏」。

The authors list several limitations themselves. First, generation is incompletely evaluated: the paper admits that "due to time constraints, we did not conduct a full-scale evaluation of the generation capabilities," deferring samples and interactive demos to a supplementary website rather than reporting systematic quantitative results — meaning the generative half of the two-pass architecture has not actually been rigorously checked for output quality. Second, transcription quality is unverified: Transkun is called "note-level state of the art," but the authors "did not explicitly check transcription quality (including pedal artefacts)," meaning the dataset's own labels may carry unknown transcription error. Third, pedal handling is limited: Aria's tokenizer has no explicit pedal tokens (sustain is folded into note durations), so the comparison against the Aria baseline cannot isolate pedalling as a discrete expressive cue. Fourth, there's a data-rights concern: although the recordings are publicly available, uploaders' underlying rights were never waived, and the authors commit to removing content on request — meaning the dataset's long-term availability is uncertain. Overall, the paper's core claim (representation learning) is validated fairly rigorously, but the paired generation capability is nearly untested — readers shouldn't infer from "the JEPA representation learns well" that "this system can also generate high-quality performances."

討論Discussion

這篇論文自稱是「第一個用JEPA做符號鋼琴演奏聯合生成與表徵學習」的工作,把樂譜-演奏配對當成自然的兩視角結構。從結果來看,MAJEPPA的各種變體在大多數任務上都超越四個基線(Aria、Moonbeam、MusicBERT、CLaMP 3):蕭邦排名從Aria的47.5%提升到59.7%,技巧偵測從66.2%提升到79.0%,PISA品質回歸的MAE從0.122降到0.090。消融實驗顯示單獨用ℒ_piece就已經能跟基線競爭,加上ℒ_cond對「標籤可分辨」型的任務有幫助,加上ℒ_self能進一步降低回歸誤差,但會稍微犧牲鋼琴家辨識的準確度——這代表「風格身分辨識」跟「演奏品質評估」在表徵空間裡可能存在某種張力,不是完全同向的目標。質性分析也頗有意思:七段YouTube上的練習歷程裡,session編號跟主成分之間的Spearman相關係數達到0.41,顯示模型在沒有時間監督訊號的情況下,學到了某種「練習進步」的方向性;UMAP投影也顯示,節奏型錯誤(搶拍、雙手脫節)跟音高型錯誤(摸錯鍵、彈錯音)在潛在空間裡形成了可分的群集。這些發現支持了論文的核心主張——一個統一的表徵空間,確實能同時承載風格、準確度與教學結構等多種訊號,而不需要為每個任務單獨訓練模型。不過如前述,生成能力那一半仍是留白,這意味著「統一表徵」目前主要體現在評估與辨識任務上,能不能真正支撐高品質的可控生成,還是一個懸而未決的問題。

The paper positions itself as "the first JEPA to model for joint symbolic piano-performance generation and representation learning," treating score-performance pairs as a natural two-view structure. On results, MAJEPPA variants outperform four baselines (Aria, Moonbeam, MusicBERT, CLaMP 3) on most tasks: Chopin ranking rises from Aria's 47.5% to 59.7%, technique detection from 66.2% to 79.0%, and PISA quality-regression MAE drops from 0.122 to 0.090. Ablations show ℒ_piece alone is already competitive with baselines, adding ℒ_cond helps tag-discriminative tasks, and adding ℒ_self further reduces regression error but slightly hurts pianist identification — suggesting some tension between "style identity" and "quality assessment" in the representation space rather than both pulling in the same direction. The qualitative analysis is also interesting: across seven YouTube practice journeys, Spearman correlation between session index and the leading principal component reaches 0.41, showing the model captures a directional sense of practice progress without any temporal supervision signal; UMAP projections likewise show timing-type mistakes (rushed entries, hands falling out of sync) and pitch-type mistakes (mistouches, wrong notes) forming separable clusters in latent space. These findings support the paper's central claim — that a unified representation space really can carry style, accuracy, and pedagogical structure simultaneously without training a separate model per task. But as noted above, the generative half remains untested, meaning the "unified representation" so far has mainly proven itself on assessment and identification tasks, and whether it can genuinely support high-quality controllable generation remains an open question.

MI-MIDI: Mechanistic Interpretability of Text-to-MIDI Generation Models via Probing, Lenses and Steering

Jakub Poćwiardowski, Mateusz Modrzejewski
arXiv:2608.06638 · cs.SD · 投稿submitted 2026-08-06
abspdfhtmlcited by
為什麼挑這篇：機制可解釋性（mechanistic interpretability）這套從語言模型研究發展出來的工具——線性探針、logit/tuned lens、activation patching、方向性操控——過去幾乎只用在音訊音樂模型（例如 MusicGen），這篇是少數把整套工具搬到符號音樂（text-to-MIDI）模型上的研究，而且刻意選了架構迥異的兩個模型（cross-attention 的 text2midi 與把 MIDI token 塞進 Llama 的 MIDI-LLM）對照分析，發現兩者形成音樂預測的方式截然不同——這個架構決定可操控性的發現，對想要控制生成模型輸出（例如調音域、調複音密度）的人有直接的工程意義，所以標記為深度分析。Why this one: Mechanistic interpretability tooling developed for language models — linear probes, logit/tuned lenses, activation patching, directional steering — has almost exclusively been applied to audio music models (e.g. MusicGen). This paper is one of the first to bring the full toolkit to symbolic, text-to-MIDI models, and deliberately contrasts two architecturally different systems (the cross-attention-based text2midi versus MIDI-LLM, which grafts MIDI tokens onto a Llama backbone) to find that they form musical predictions in fundamentally different ways. That architecture-determines-controllability finding has direct engineering relevance for anyone trying to steer generation output (register, polyphony density, etc.), which is why it's flagged as a deep dive.

動機Motivation

近年語言模型的機制可解釋性研究發展出一整套成熟工具：用線性探針檢驗某個概念是否可以從內部激活值線性解碼出來；用 logit lens／tuned lens 觀察模型在每一層「如果現在就輸出，會輸出什麼」；用 activation patching 找出資訊在哪一層被因果性地綁定到輸出；用方向性操控（steering）驗證某個方向的激活加法能不能可控地改變輸出。這些工具在音樂生成模型上的應用幾乎全部集中在音訊模型（如 MusicGen），符號音樂生成——尤其是最近因為 MIDICaps 這類資料集興起的文字轉 MIDI 模型——完全沒人碰過。作者提出三個核心問題：這些模型內部到底編碼了哪些音樂概念（音高、樂器、和聲）？這些概念在網路的哪一層、什麼時候形成最終預測？以及這些被解碼出來的資訊是不是「因果上真的有用」，能不能拿來操控生成結果？這篇論文的目標就是把語言模型可解釋性的方法論第一次系統性地搬到符號音樂生成模型上，並且刻意選兩個架構差異很大的模型做對照，檢驗「架構設計」本身如何決定音樂概念的表徵方式與可操控性。

Mechanistic interpretability research on language models has matured into a full toolkit: linear probes test whether a concept is linearly decodable from internal activations; logit/tuned lenses reveal what a layer would output if generation stopped there; activation patching locates where information becomes causally bound to the output; and directional steering tests whether adding an activation vector can controllably shift the output. Applied to music generation, this toolkit has almost exclusively targeted audio models like MusicGen — symbolic music generation, especially the recent wave of text-to-MIDI models enabled by datasets like MIDICaps, has gone entirely unexamined. The authors pose three core questions: what musical concepts (pitch, instrument, harmony) are actually encoded internally; at which layer and when do these concepts crystallize into a final prediction; and is the decoded information causally useful — can it actually steer generation? The paper's goal is to bring language-model interpretability methodology to symbolic music generation systematically for the first time, deliberately contrasting two architecturally distinct models to examine how architecture itself determines how musical concepts are represented and how controllable they are.

背景與相關研究Introduction & Prior Work

背景涵蓋三條線：文字條件式音樂生成（特別是 MIDICaps 這類資料集，讓端到端的文字轉 MIDI 模型變得可行）；機制可解釋性技術本身（線性探針、logit/tuned lens、activation steering，均源自語言模型研究）；以及既有的音樂模型可解釋性工作（過去幾乎只做音訊模型如 MusicGen，符號系統幾乎是空白）。研究對象選了兩個代表性但架構迥異的系統：text2midi 是編碼器-解碼器架構，用凍結的 Flan-T5 當文字編碼器，透過 cross-attention 把文字資訊持續餵給 18 層、768 維隱藏層的解碼器，用 REMI+ 做符號音樂的 tokenization；MIDI-LLM 則是把 Llama 3.2 1B（16 層、2048 維隱藏層）這個純解碼器語言模型的詞表直接擴充，塞進 MIDI token，用 context 方式（而不是 cross-attention）做文字條件，tokenization 用 AMT 格式。這個選擇本身就是研究設計的核心：一個是「音樂 token 和文字 token 從一開始就在共享的殘差流裡競爭」的架構，一個是「文字資訊透過獨立通道持續注入」的架構,這兩種條件方式理論上應該導致完全不同的資訊處理模式。

The related work spans three threads: text-conditioned music generation, particularly datasets like MIDICaps that made end-to-end text-to-MIDI models feasible; the mechanistic interpretability techniques themselves (linear probes, logit/tuned lenses, activation steering), all originating in language-model research; and prior music-model interpretability work, which has almost exclusively targeted audio models like MusicGen, leaving symbolic systems essentially unexamined. The two studied systems are chosen to be architecturally distinct: text2midi is an encoder-decoder model with a frozen Flan-T5 text encoder feeding a REMI+-tokenized, 18-layer, 768-hidden-dimension decoder via cross-attention conditioning; MIDI-LLM instead extends a Llama 3.2 1B decoder-only language model (16 layers, 2048 hidden dimensions) with an expanded vocabulary that includes MIDI tokens, conditioning on text via context rather than cross-attention, and using AMT-style tokenization. This choice is itself the core of the research design: one architecture has music and text tokens competing in a shared residual stream from the start, while the other injects text information through a persistently separate channel — two conditioning strategies that should, in principle, produce very different information-processing patterns.

方法Method

方法分四層。線性探針：在每一層的激活值上訓練 L2 正則化邏輯回歸探針，檢驗音高類別、樂器家族、和弦性質、和聲功能、推估調性等概念能不能線性解碼，同時對真實生成內容與來自 SynTheory 資料集的受控合成範例都做探測，並用打亂標籤的對照探針確認結果反映的是真實表徵而非探針本身的容量。Logit lens 與 tuned lens：經典 logit lens 直接看每一層「現在停下來會輸出什麼」；對於詞表混雜文字與音樂 token 的 MIDI-LLM，額外分析限制在音樂詞表內的分佈；tuned lens 額外訓練一個小型仿射轉換器，把中間層表徵映射到最終層的座標系，用來區分「預測在後段真的發生劇烈變化」還是「只是座標系旋轉」這兩種可能。Activation patching：把某一層的激活值替換成對比提示詞（例如鋼琴 vs. 小提琴）產生的激活值，量測樂器資訊在哪一層被因果性地「綁定」進生成內容，藉此定位資訊整合發生的深度。方向性操控：用對比提示詞的激活值算出「均值差」方向，加回殘差流裡，並設計了一個新穎的雙向協議——分別檢驗「往正向加」與「往負向加」是否會產生方向相反的效果（真正的方向性控制）還是只是對稱的漂移，追蹤的指標包括音密度（代表節奏/能量）、平均 MIDI 音高（代表音域）、同時發聲的音符數（代表複音密度）。實驗規模包括 1000 個隨機生成提示用於完整生成探測、200 個序列子樣本用於逐 token 探測、5 折分組交叉驗證、tuned lens 用 6 萬個 token 位置訓練、5 萬個位置留作驗證，操控實驗涵蓋 10680 個序列，並用 2000 次自助抽樣算信賴區間。

The methodology has four layers. Linear probing: L2-regularized logistic regression probes are fit on activations at each layer to test whether pitch class, instrument family, chord quality, harmonic function, and estimated key are linearly decodable, run on both realistic full generations and controlled synthetic examples from the SynTheory dataset, with shuffled-label control probes confirming results reflect genuine representational content rather than probe capacity. Logit and tuned lens: the classic logit lens shows what each layer would predict if generation stopped there; for MIDI-LLM, whose vocabulary mixes text and music tokens, the analysis is additionally restricted to the musical-vocabulary distribution; the tuned lens trains a small affine translator mapping intermediate representations into the final layer's basis, distinguishing genuine late-stage prediction refinement from mere basis rotation. Activation patching: activations at a given layer are swapped with those from a contrasting prompt (e.g. piano vs. violin) to measure at which layer instrument information becomes causally bound into generation, localizing the depth of information integration. Directional steering: difference-in-means vectors computed from contrastive prompts are additively injected into the residual stream, using a novel bidirectional protocol that separately tests whether adding the vector in the positive versus negative direction produces genuinely opposite effects (true directional control) versus merely symmetric drift, tracking note density (tempo/energy proxy), mean MIDI pitch (register), and simultaneous note count (polyphony). Experimental scale includes 1,000 randomly generated prompts for full-generation probing, 200-sequence subsamples for token-level probing, 5-fold grouped cross-validation, a tuned lens trained on 60,000 token positions with 50,000 held out for evaluation, steering experiments spanning 10,680 sequences, and 2,000 bootstrap resamples for confidence intervals.

限制Limitations

作者列出五點限制。均值差方向的品質問題：對比提示詞在詞彙和音樂內容上同時有差異，方向的「乾淨程度」直接取決於對比組設計得好不好，混雜的對比可能讓操控方向不夠純粹。指標間的相依性：音符密度（用來代表節奏/能量）本身跟複音密度高度相關，兩者不是完全獨立的測量，操控其中一個難免影響另一個，讓因果解讀打了折扣。標籤品質：序列層級的調性估計用 Krumhansl-Schmuckler 演算法，本身就有誤差，一些較弱的高層概念表徵結果可能只是反映標籤噪音而非模型真的沒學到。抽象概念難以量化：更抽象的音樂性質（例如整體樂句結構、情緒）在多軌 MIDI 裡難以明確定義與測量，完全排除在量化分析之外。模型範圍：只研究了兩個模型，無法把「條件機制的差異」和「其他架構差異（模型大小、tokenization、訓練資料）」完全切開，觀察到的差異有可能部分來自條件機制之外的因素。

The authors list five limitations. Difference-in-means direction quality: contrastive prompts vary both lexically and musically, so the cleanliness of a steering direction depends heavily on how well-matched the contrast set is, and mixed contrasts can leave the direction impure. Metric interdependence: note density (used as a tempo/energy proxy) correlates strongly with polyphony, so the two are not fully independent measurements, and steering one inevitably affects the other, weakening causal interpretation. Label quality: sequence-level key estimates rely on the Krumhansl-Schmuckler algorithm, which itself carries error, so some weak higher-level concept representations may reflect label noise rather than a genuine gap in what the model learned. Hard-to-quantify abstraction: more abstract musical properties (overall phrase structure, mood) are difficult to define and measure unambiguously in multi-track MIDI and are excluded from the quantitative analysis entirely. Model scope: only two models are studied, so differences attributable to the conditioning mechanism cannot be fully separated from other architectural differences (model size, tokenization, training data) — the observed contrasts may partly reflect factors beyond conditioning alone.

討論Discussion

最核心的發現是兩個模型形成音樂預測的方式截然不同，而這個差異可以直接追溯到條件機制的設計。text2midi 用 cross-attention 讓解碼器在每一層都能重新查閱編碼過的文字提示，結果是預測在各層逐步、漸進地精煉，沒有單一層出現劇烈跳躍，樂器資訊的整合也是分散在各層，沒有集中的深度峰值——這種「隨時可查閱提示」的設計讓操控也變得穩定：在所有層同時注入操控向量依然穩定，且方向性最乾淨。MIDI-LLM 則呈現截然不同的兩階段模式：前 12 層幾乎完全停留在繼承自文字模型的表徵基底裡，音樂詞表的預測準確率接近零，詞表機率質量維持在跟詞表大小成比例的約 30%；到第 13 層開始劇烈轉向，第 15 層音樂詞表機率質量衝到約 95%，這個轉向還有明確的順序：先是特殊符號、再是音符、最後才是時間/音長token。用 tuned lens 檢驗發現這個劇烈跳躍有一部分只是座標系旋轉（不是真正新資訊的產生），但排除座標系效應後仍有實質的預測精煉在發生。這個「資訊晚期才突然綁定」的模式直接反映在操控實驗上：MIDI-LLM 只有單層注入才穩定，多層同時注入操控向量會累積干擾，操控強度被限制在 α=0.75 這個上限；而 text2midi 全層注入依然穩定。這給出一個可以直接落地的工程結論：用 cross-attention 條件的模型，操控時可以放心用全層注入；用 LLM 改造、共享殘差流條件的模型，操控必須挑單一層小心注入，貪心地全層加會讓效果崩掉。這種「架構設計決定表徵形成路徑，進而決定可操控性上限」的因果鏈，是這篇論文對可解釋性研究和實務操控應用都有貢獻的地方。

The central finding is that the two models form musical predictions in fundamentally different ways, traceable directly to their conditioning mechanism. text2midi's cross-attention lets the decoder re-consult the encoded text prompt at every layer, producing gradual, layer-by-layer prediction refinement with no single sharp jump, and instrument-information integration is distributed across depth with no concentrated peak — this "always-available prompt" design also makes steering stable: injecting a steering vector at every layer simultaneously remains stable and yields the cleanest directional control. MIDI-LLM shows a starkly different two-stage pattern: the first 12 layers remain almost entirely within a basis inherited from the underlying text model, with near-zero musical-vocabulary prediction accuracy and vocabulary probability mass sitting at roughly 30% — proportional to vocabulary size — before rotating sharply starting at layer 13, reaching roughly 95% musical-vocabulary mass by layer 15, in an ordered sequence: special tokens first, then notes, then timing/duration tokens. The tuned lens shows part of this sharp jump is merely basis rotation rather than genuinely new information, though substantial real prediction refinement remains even after accounting for that. This late, sudden-binding pattern shows up directly in the steering results: MIDI-LLM is stable only with single-layer injection, while injecting the steering vector across all layers accumulates disruptive interference, capping usable strength at α=0.75; text2midi, in contrast, remains stable with all-layer injection. This yields directly usable engineering guidance: for cross-attention-conditioned models, all-layer steering injection is safe; for LLM-adapted models sharing a residual stream between prompt and generation, steering must target a single carefully chosen layer, since greedy all-layer injection collapses performance. This causal chain — architecture determines representation-formation pathway, which in turn determines the ceiling on controllability — is the paper's core contribution to both interpretability research and practical steering applications.

Equivariant Music Transformer

等變音樂 Transformer

Zixun Guo, Simon Dixon
arXiv:2608.03920 · cs.SD · 投稿submitted 2026-08-05
abspdfhtmlcited by
為什麼挑這篇：這篇提出「等變性不會隨著模型變大或訓練變久而自動出現」的實證證據，並且用一個乾淨的自蒸餾式輔助損失函式把等變性直接塞進訓練目標裡，而不是像過去那樣靠資料增強或架構技巧繞路。研究設計成三組對照——不加輔助損失、資料增強、模型層級正則化——讓因果關係看得很清楚。Why this one: It gives concrete evidence that equivariance does not emerge from scale or longer training, then folds it directly into the training objective via a self-distillation auxiliary loss instead of leaning on data augmentation or architectural tricks. The three-way comparison (no auxiliary loss vs. augmentation vs. model-level regularization) isolates the causal claim cleanly.

動機Motivation

人類聽音樂時，一段旋律不管移調多少半音、往前或往後平移多少拍，聽起來都還是「同一個東西」——這是一種等變性（equivariance）：輸入做了某種變換，輸出應該跟著做出可預期的對應變換。symbolic music transformer 理論上該有這個特性，但作者觀察到一個不尋常的現象：目前主流的自迴歸 transformer，只用 next-token cross-entropy 訓練，並不會自動學到這個特性，而且模型越大、訓練越久，反而越不等變——模型把容量拿去記憶絕對位置模式，而不是共享的音樂結構。這篇論文的出發點就是要質疑「等變性會隨著規模湧現」這個常見假設，並且直接在訓練目標裡加入監督訊號，強迫模型學到它。

When a listener hears a melody transposed up a few semitones or shifted a few beats in time, it still registers as "the same" musical idea — a property called equivariance: a transformation of the input should produce a predictable, corresponding transformation of the output. Symbolic music transformers ought to have this property, but the authors report something counter-intuitive: today's standard autoregressive transformers, trained purely with next-token cross-entropy, do not acquire it automatically — and larger models trained longer become *less* equivariant, apparently spending their extra capacity memorizing absolute patterns rather than shared musical structure. The paper's starting point is to question the common assumption that equivariance emerges from scale, and to instead inject it directly into the training objective as an explicit supervisory signal.

背景與相關研究Introduction & Prior Work

過去讓模型「感知」平移不變性的做法大致三類：一是輸入端做特徵工程（例如用相對音高、相對時值編碼取代絕對值）；二是架構上動手腳，像相對位置編碼（relative position embedding）；三是資料增強，把同一段音樂做隨機移調、平移後都丟進去訓練。這三種做法在音高估計、速度估計、表徵學習等 MIR 任務上都證實有效，但作者指出一個共同盲點：不管輸入端或架構端做了什麼調整，幾乎所有生成模型的訓練目標最後都還是標準的 next-token cross-entropy，從來沒有人在「模型層級」明確要求等變性作為訓練目標的一部分。這篇論文接的正是這個空白：把等變性從「盼望架構設計帶來的副產物」提升成「顯式的訓練目標」。

Prior attempts to give models translation-invariant perception of music fall into three camps: input-level feature engineering (relative rather than absolute pitch/duration encodings), architectural modifications such as relative position embeddings, and data augmentation via random transposition and time-shifting during training. Each has shown benefits for MIR tasks like pitch estimation, tempo estimation, and representation learning. But the authors point to a shared blind spot: regardless of what happens at the input or architecture level, nearly every generative model's training objective still defaults to plain next-token cross-entropy — no one has explicitly supervised equivariance as a model-level training objective. This paper fills exactly that gap, promoting equivariance from a hoped-for side effect of architecture choices to an explicit training target.

方法Method

EMT 用雙分支架構同時優化兩個目標。主分支就是標準自迴歸 next-token 預測，用 cross-entropy loss。輔助分支做的是「自蒸餾式」等變性正則化：對輸入序列 x 套用一個隨機的音樂變換 T（音高平移、時間平移），丟進模型得到變換後的預測分佈 p^T，再把預測分佈套用反變換 T^-1，拿去跟原始輸入（不做變換）得到的預測分佈 p 做 KL 散度比較——理論上，如果模型真的等變，「先變換輸入再反變換輸出」應該要等於「完全不變換」。這裡的關鍵設計是對原始預測 p 做 stop-gradient，避免模型學到讓兩邊都塌縮成同一個平凡解來騙過損失函式。總損失是兩者加權和，權重 λ 設得很小（0.001），等變損失是輔助角色而非主導。

架構本身建立在 Moonbeam 之上，做了幾個 MIR 特化的修改：改用絕對 onset time 而不是相對 delta，方便變換能均勻套用到輸入輸出兩端；把八度與音高類別合併成一本統一的 pitch 字典，簡化變換操作；用 token delay pattern 取代原本的 GRU 解碼器來捕捉 onset、pitch、duration、instrument、velocity 五個屬性之間的相依關係；embedding 用直接相加而非串接，增加每個屬性的表達力。此外還疊加了兩個既有的等變性技巧作為對照與互補：Fundamental Music Embedding（讓輸入層本身帶有音樂距離感）和 Multi-Dimensional Relative Attention（用相對位置而非絕對位置編碼）。

訓練資料是 LakhMIDI：消融實驗用 LMD-clean 的 7.9 萬條序列（約 8000 萬 token），主觀聆聽評測用完整 LMD。模型不大，12 層、hidden size 768，約 9600 萬參數，兩張 A100/H100 分散式訓練。變換範圍是 ±12 半音、0 到 5 秒（0.25 秒為單位），測試時故意用更大範圍（±24 半音、0 到 10 秒）做分佈外評估。

EMT jointly optimizes two branches. The main branch is a standard autoregressive next-token predictor trained with cross-entropy loss. The auxiliary branch implements equivariance as a self-distillation regularizer: a random musical transformation T (pitch shift, time shift) is applied to the input sequence x, the model's prediction on the transformed input p^T is computed, an inverse transform T^-1 is applied to that prediction, and the result is compared via KL divergence against the model's prediction on the untransformed input p. In a perfectly equivariant model, "transform the input then invert the output" should match "never transforming it at all." A stop-gradient on the untransformed anchor prediction prevents the trivial collapse where both branches converge to the same degenerate output just to cheaply minimize the loss. The total loss is a weighted sum with a small λ=0.001, keeping the equivariance term auxiliary rather than dominant.

The backbone builds on Moonbeam with several MIR-specific modifications: absolute onset times instead of relative deltas so transformations apply uniformly across input and output; a unified pitch dictionary merging octave and pitch-class tokens to simplify transformation; a token delay pattern replacing the original GRU decoder to capture dependencies among onset, pitch, duration, instrument, and velocity; and additive rather than concatenative embeddings for greater per-attribute expressiveness. Two existing equivariance techniques are layered on as complementary feature-level engineering: Fundamental Music Embedding (a music-distance-aware input layer) and Multi-Dimensional Relative Attention (relative rather than absolute positional encoding).

Training uses the LakhMIDI dataset: ablations use LMD-clean (79k sequences, ~80M tokens), and the subjective listening study uses the full LMD. The model is modest — 12 layers, hidden size 768, ~96M parameters, trained on 2 A100/H100 GPUs. Transformations span ±12 semitones and 0-5 seconds (0.25s steps) during training, with deliberately wider out-of-distribution ranges (±24 semitones, 0-10s) at test time.

限制Limitations

論文本身很誠實地把「等變性不會隨規模湧現」講成一個負面結果，但這個結論的證據鏈其實依賴特定的架構家族（Anticipatory Music Transformer、MIDI-LLM）和特定資料集（LakhMIDI），換一種完全不同的 tokenization 或訓練語料，趨勢是否一樣穩健並未驗證。其次，λ=0.001 是憑經驗選出來的單一數值，論文沒有做完整的敏感度分析說明這個超參數在不同資料規模或模型大小下要怎麼調，若 λ 選得不好，等變損失可能反過來傷害生成品質。第三，主觀聆聽測試只找了 12 位受試者評估，樣本數偏小，雖然用 Wilcoxon 檢定確認顯著性，但外部效度有限。最後，變換只涵蓋音高平移與時間平移這兩種最基本的音樂對稱性，速度伸縮（tempo rubato）、調式轉換等其他音樂上有意義的變換完全沒有討論，等變性框架能否推廣到這些變換也是未知數。

The paper is admirably honest in framing "equivariance does not emerge from scale" as a negative result, but the evidence chain rests on a specific architecture family (Anticipatory Music Transformer, MIDI-LLM) and a specific corpus (LakhMIDI); whether the trend holds under a different tokenization scheme or training corpus is untested. Second, λ=0.001 is a single empirically chosen value without a full sensitivity analysis across model or dataset scale — a poorly chosen λ could let the equivariance term actively hurt generation quality. Third, the subjective listening study used only 12 participants; while a Wilcoxon test confirms statistical significance, the external validity of such a small panel is limited. Finally, the transformations studied are limited to the two most basic musical symmetries — pitch shift and time shift — leaving tempo rubato, mode changes, and other musically meaningful transformations entirely unaddressed, so it remains open whether the equivariance framework generalizes to them.

討論Discussion

這篇論文最有意思的地方不是「加了一個新 loss 讓模型變好」這種常見套路，而是它先做了一個扎實的診斷實驗，證明業界預設「規模夠大自然會學到好的歸納偏誤」這個信念在等變性這件事上是錯的——甚至是反過來的。這對整個 MIR 領域的啟示可能比 EMT 本身的架構更重要：如果連「移調不變性」這種音樂裡最基本、最容易驗證的對稱性都不會隨規模自然浮現，那麼其他更複雜的音樂結構性質（比如曲式的層級性、和聲功能的等價關係）恐怕更不會白白出現，勢必要靠明確的訓練目標或架構偏誤去誘導。另外，EMT 用比 Anticipatory 模型小得多的參數量就達到相近的生成品質，同時等變性大幅提升，這說明「顯式正則化」有時候比「單純擴大模型規模」更划算——對計算資源有限的研究者是個實用的訊息。比較可惜的是論文沒有討論等變損失對訓練時間、記憶體開銷的實際代價，這在評估「值不值得採用」時是缺一角的資訊。

The paper's most interesting contribution isn't "add a new loss and things get better" — it's the diagnostic work up front, which shows that the field's implicit assumption, that sufficient scale naturally yields good inductive biases, is wrong, even inverted, for equivariance. That may matter more for MIR broadly than EMT's architecture itself: if even the most basic, easily verifiable musical symmetry (transposition invariance) doesn't emerge from scale alone, more complex structural properties of music (hierarchical form, functional harmonic equivalence) are unlikely to emerge for free either, and will likely need explicit training objectives or architectural biases to induce. It's also notable that EMT matches Anticipatory-scale generation quality with far fewer parameters while gaining substantially in equivariance — suggesting explicit regularization can sometimes be a better bargain than simply scaling up, a practically useful signal for compute-constrained researchers. One gap: the paper doesn't discuss the actual training-time or memory overhead of the auxiliary equivariance branch, which matters for judging whether the tradeoff is worth adopting.

HARP: Harmonic-Aware Residual Partitioning for Neural Audio Codecs

HARP：神經音訊編解碼器的諧波感知殘差分割

Qiaoyu Yang, Lixing He, Binyue Deng, Weifeng Zhao
arXiv:2607.16657 · cs.SD · 投稿submitted 2026-07-18
abspdfhtmlcited by
為什麼挑這篇：架構完全不動、只改訓練損失，就讓 RVQ 的每一階對應到一個頻帶——這種「零推論成本」的novel技術在表徵學習裡很少見，而且對音樂特別有意義：泛音與基頻的關係正是它想保住的東西。Why this one: It changes only the training loss, not the architecture, yet makes each RVQ stage correspond to a frequency band — a genuinely novel zero-inference-cost technique, and one that matters especially for music, since the fundamental-overtone relationship is exactly what it preserves.

動機Motivation

RVQ 音訊 codec（SoundStream、EnCodec、DAC 一系）預設對所有頻率一視同仁，結果是 codebook 在頻譜上糾纏：每一階量化器學到的是頻率的不可預測混合，而非某個特定頻帶。這造成一個實務痛點——低位元率時我們會截斷後面幾階，但截掉的是「一團說不清是哪些頻率的東西」，退化行為因此不可控、產生的失真也不穩定。

既有的補救是平行頻帶分解：把音訊切成獨立頻帶各自編碼。這確實建立了頻率階層，卻付出另一個代價——潛空間被切碎，跨頻帶的相干性消失。對音樂而言這特別致命：一個 200 Hz 的基頻與它在 800 Hz 的泛音是同一個發聲事件的兩個面向，把它們丟給兩個互不通訊的編碼器，重建出來的諧波關係就會失真。

作者把這兩者定調為互補的失效模式：標準 RVQ 有諧波脈絡但沒有頻率特化，平行分解有頻率階層但破壞跨頻帶諧波。HARP 想同時要兩者。

RVQ audio codecs (the SoundStream / EnCodec / DAC lineage) treat all frequencies uniformly, so codebooks become spectrally entangled: each quantiser stage learns an unpredictable mixture of frequencies rather than a specific band. This creates a practical problem — at low bitrates we truncate later stages, but what gets removed is an indeterminate mix of frequencies, so degradation is uncontrolled and the resulting distortion is erratic.

The existing remedy is parallel band decomposition: split the audio into independent bands and encode each separately. That does establish a frequency hierarchy, but at another cost — the latent space fragments and cross-frequency coherence is lost. For music this is especially damaging: a 200 Hz fundamental and its 800 Hz partial are two facets of one sounding event, and handing them to two encoders that never communicate distorts the reconstructed harmonic relationship.

The authors frame these as complementary failure modes: standard RVQ has harmonic context but no frequency specialisation; parallel decomposition has frequency hierarchy but breaks cross-band harmonics. HARP wants both.

背景與相關研究Introduction & Prior Work

定位很清楚：這不是新架構，是訓練策略。對照組一邊是標準 RVQ codec，另一邊是 BSCodec 這類平行頻帶分解方法。論文的三項貢獻宣稱依序為：把上述兩種失效模式指認為互補問題；提出僅靠監督訊號就在單一 RVQ 內部建立頻率階層的訓練法；以及在語音、音樂、一般音訊上勝過兩邊基線，並釋出模型、訓練腳本與音檔範例。

值得注意的是它的工程賣點——推論路徑與標準 RVQ 完全相同。這代表任何已經在用 RVQ codec token 的下游系統（音樂 LM、TTS、音訊理解）都能直接換上，不必改任何介面。

The positioning is explicit: this is not a new architecture but a training strategy. It is compared against standard RVQ codecs on one side and parallel band decomposition methods such as BSCodec on the other. The three claimed contributions are: identifying the two failure modes above as complementary; proposing a training method that imposes a frequency hierarchy inside a single RVQ through supervision alone; and beating both baselines on speech, music and general audio, with public models, training scripts and audio samples.

The engineering selling point is worth noting — the inference path is identical to standard RVQ. Any downstream system already consuming RVQ codec tokens (music LMs, TTS, audio understanding) can swap it in without changing any interface.

方法Method

三個機制疊起來構成 HARP。

1. 頻率有序分組。 把 L 個 RVQ 階段分成 K 個依頻率排序的組。預設 K=4、L=9：第 0 組（低音）階段 1–3，對應 0–1 kHz；第 1 組（中低）階段 4–5，1–4 kHz；第 2 組（中高）階段 6–7，4–10 kHz；第 3 組（高音）階段 8–9，10–22 kHz。注意分配是不均勻的——低頻拿到最多階段，符合聽覺與音樂訊號的能量分布。

2. 累積解碼（Cumulative Decoding）。 這是保住諧波脈絡的關鍵。第 k 組的重建使用所有累積的低頻潛表示 ẑ≤k = Σ_{j≤k} Σ_{ℓ∈S_j} q^(ℓ)，也就是說解碼高頻時，解碼器看得到所有已重建的低頻內容——200 Hz 的基頻可以指引 800 Hz 泛音的重建。接著用 stop-gradient 把第 k 組自己的貢獻隔離出來：x̂_k = G(sg[ẑ≤k−1] + ẑ_k) − sg[x̂≤k−1]。stop-gradient 在這裡是防止梯度回流污染前面的組，讓每組專注在自己的增量上。

3. 子帶監督與軟頻帶加權。 每組的波形增量對一個加權 mel 頻譜目標計算 L1：L_band^(k) = Σ_m Σ_t w_k(m) |M_{m,t}(x̂_k) − M_{m,t}(x)|。權重 w_k 不是硬切的二值遮罩，而是可學習的高斯：w̃_k(m) = β + (1−β)·exp(−(m−μ_k)²/2σ_k²)，其中 β=0.3 是地板值（確保組外頻率不會被完全忽略），μ_k（中心）與 σ_k（頻寬）可學習，初始化為 σ_k = M/(3K)、M=80 個 mel bin 涵蓋 0–22 kHz，權重再正規化以維持損失量級一致。作者明講頻帶邊界是「透過軟監督施加的近似目標，不是剛性的二值約束」。

總損失只是在標準 codec 損失後面加一項：L = L_rec + λ_adv·L_adv + λ_fm·L_fm + λ_vq·L_vq + λ_band·Σ_k L_band^(k)。就這樣——沒有新模組、沒有新參數（除了 K 組的 μ、σ），推論時完全等同標準 RVQ。

Three mechanisms stack to make HARP.

1. Frequency-ordered grouping. The L RVQ stages are split into K frequency-ordered groups. The default is K=4 over L=9 stages: group 0 (bass) stages 1–3 for 0–1 kHz; group 1 (low-mid) stages 4–5 for 1–4 kHz; group 2 (high-mid) stages 6–7 for 4–10 kHz; group 3 (treble) stages 8–9 for 10–22 kHz. Note the allocation is deliberately uneven — low frequencies get the most stages, matching both perception and the energy distribution of musical signals.

2. Cumulative decoding. This is what preserves harmonic context. Group k's reconstruction uses all accumulated lower-frequency latents, ẑ≤k = Σ_{j≤k} Σ_{ℓ∈S_j} q^(ℓ), so when decoding high frequencies the decoder can see everything already reconstructed below — a 200 Hz fundamental guides reconstruction of its 800 Hz partial. Group k's own contribution is then isolated with a stop-gradient: x̂_k = G(sg[ẑ≤k−1] + ẑ_k) − sg[x̂≤k−1]. The stop-gradient prevents gradient bleed into earlier groups so each group focuses on its own increment.

3. Subband supervision with soft band weighting. Each group's waveform increment is scored by an L1 loss against a weighted mel-spectrogram target: L_band^(k) = Σ_m Σ_t w_k(m) |M_{m,t}(x̂_k) − M_{m,t}(x)|. The weights w_k are not hard binary masks but a learnable Gaussian: w̃_k(m) = β + (1−β)·exp(−(m−μ_k)²/2σ_k²), where β=0.3 is a floor (so out-of-band frequencies are never fully ignored), and μ_k (centre) and σ_k (bandwidth) are learned, initialised at σ_k = M/(3K) with M=80 mel bins spanning 0–22 kHz, then normalised to keep loss magnitudes consistent. The authors are explicit that band boundaries are "approximate targets enforced through soft supervision, not rigid binary constraints."

The total loss simply appends one term to the standard codec objective: L = L_rec + λ_adv·L_adv + λ_fm·L_fm + λ_vq·L_vq + λ_band·Σ_k L_band^(k). That is all — no new modules, no new parameters beyond K pairs of μ and σ, and inference identical to standard RVQ.

限制Limitations

作者沒有寫明確的 limitations 段落，這本身是這篇最明顯的弱點；以下是我讀後的判斷，請視為我的評論而非作者陳述。

數據透明度不足：論文正文我能取到的部分並未完整報出客觀指標的數值（如 SI-SNR、PESQ、ViSQOL），也沒有 MUSHRA 的受試者人數、分數與信賴區間，只說「在兩個位元率條件下有感知改善」。訓練資料僅以「語音、音樂、一般音訊」帶過，未指名資料集，這讓與 DAC／EnCodec 的比較難以校準。

設計上的疑問：K=4 與四個頻帶切點（1 / 4 / 10 / 22 kHz）是手工設定，論文未報告對 K 或切點的敏感度分析；高斯權重可學習雖然優雅，但 μ_k 在訓練中可能漂移甚至跨組重疊，論文沒有展示最終學到的 μ、σ 值——這是我最想看到的一張圖。此外，β=0.3 的地板意味著每組其實仍看到全頻譜的 30% 權重，所謂「特化」是程度問題而非二分。

最關鍵的空缺是動機與驗證之間的落差：論文以「截斷 codebook 時退化不可控」作為主要動機，卻（就我取得的內容而言）沒有把「不同截斷階數下的品質曲線」當作核心實驗來報告。這正是 HARP 應該最發光的場景。另外，完全沒有下游任務評估——沒有測這些頻率有序的 token 在音樂 LM、轉譜或分離上是否更好用。

The authors provide no explicit limitations section, which is itself the paper's most visible weakness. What follows is my assessment, not the authors' statements.

Reporting transparency is thin: the portion of the text I could retrieve does not give numeric values for objective metrics (SI-SNR, PESQ, ViSQOL), nor MUSHRA participant counts, scores or confidence intervals — only that perceptual improvements hold "at two bitrate conditions." Training data is described only as "speech, music, and general audio" without named datasets, which makes calibration against DAC or EnCodec difficult.

Design questions: K=4 and the band cutoffs (1 / 4 / 10 / 22 kHz) are hand-set, and no sensitivity analysis over K or the cutoffs is reported. The learnable Gaussian weighting is elegant, but μ_k may drift or even overlap across groups during training, and the paper does not show the learned μ and σ values — that is the one figure I most want to see. The β=0.3 floor also means every group still receives 30% weight across the full spectrum, so "specialisation" is a matter of degree rather than a clean split.

The most consequential gap is the distance between motivation and validation: uncontrolled degradation under stage truncation is the headline motivation, yet (in the content I could retrieve) quality-versus-truncation-depth curves are not reported as a central experiment. That is precisely where HARP should shine. There is also no downstream evaluation — nothing testing whether these frequency-ordered tokens are more useful for music LMs, transcription or separation.

討論Discussion

這篇對你的價值不在音質數字，而在它讓 codec token 有了語意上可讀的結構。

最直接的推論：如果階段 1–3 就是低頻、8–9 就是高頻，那麼建立在這種 token 上的音樂語言模型，其自迴歸順序就同時是一個頻率上的粗到細順序——先決定低音與基頻骨架，再逐步補上泛音與空氣感。這與人類編曲的思考順序意外地接近，也讓「階層式生成」有了物理意義而非只是工程分層。上一篇（2607.20253）的 hybrid-LM 正好把 c₀ 交給 8B 大模型、c₁–c₇ 交給 0.4B 小模型；若底層 codec 換成 HARP，那個 5:1 的損失加權就從「結構比細節重要」變成了「低頻比高頻重要」——兩篇擺在一起讀會很有意思。

對 MIR 更具體的機會：這是一個現成、低成本的 probing 實驗題目。取 HARP 與標準 RVQ 的 token，在相同下游任務（和弦辨識、多音高估計、樂器辨識、節拍追蹤）上做 linear probing，比較各階段 token 的資訊量分布。假設很明確——HARP 的低頻組應該在低音線與和聲根音上資訊量顯著更高。這個實驗不需要重訓 codec（作者已釋出模型），一台 GPU 就能做完，而且無論結果正反都有話可說。

The value here for you is not the audio-quality numbers but that it gives codec tokens a semantically legible structure.

The immediate consequence: if stages 1–3 are low frequency and 8–9 are treble, then a music language model built on these tokens has an autoregressive order that is simultaneously a coarse-to-fine order in frequency — settle the bass and fundamentals first, then fill in partials and air. That is unexpectedly close to how humans arrange music, and it gives hierarchical generation a physical meaning rather than merely an engineering one. The previous paper (2607.20253) assigns c₀ to an 8B model and c₁–c₇ to a 0.4B one; swap HARP in underneath and that 5:1 loss weighting shifts from "structure over detail" to "low frequencies over high" — the two papers are interesting read side by side.

A concrete MIR opportunity: this is a ready-made, cheap probing experiment. Take HARP and standard RVQ tokens, run linear probing on the same downstream tasks (chord recognition, multi-pitch estimation, instrument recognition, beat tracking), and compare how information is distributed across stages. The hypothesis is sharp — HARP's low-frequency group should carry markedly more information about bass lines and harmonic roots. The experiment needs no codec retraining (the authors released models), fits on a single GPU, and is publishable either way the result falls.
